# ManimAgent：记住动画修复经验能改善初稿——但少反思几轮不等于渲染更快

*Reel 解读：[ManimAgent: Self-Evolving Multimodal Agents for Visual Education](https://arxiv.org/abs/2606.30296v2)，标题已从 PDF 核实（HarnessRSI Daily 评分 67，★★）。代码：[jwj1342/Paper2Manim](https://github.com/jwj1342/Paper2Manim)。*

## 系统改变了自己的什么

ManimAgent 把科学论文的一个章节转成短篇 Manim 动画。它持久改变的是外部的**情景记忆库（EMB）**，不是模型权重。正通道保存提炼的成功理由与选中的代码，负通道保存失败模式、根因和修复配方。后续场景检索两条正记忆作为软性的 **Reference Examples**，三条负记忆作为 **Known Pitfalls**。所谓硬约束指提示词中的要求，并非生成代码必然遵守的形式化保证（§3）。

## 迭代回路与保留/拒绝规则

分镜交给 Coder、静态检查器与沙箱渲染器。崩溃触发纯文本审查，最多两次修复重试；相同错误重复时提前停止。可渲染场景进入独立的视觉回路，最多再修改两次。GPT-5.5 审查器观看四张关键帧，评价逻辑流程、布局/遮挡、准确性，以三者的等权平均分驱动修改。90 分自动通过；审查器裁决或预算耗尽也会终止回路。交付版本选可渲染候选中视觉分最高者，同分取较早版本。

写入记忆另有门控（§3.3）：

- **正记忆：** 选中版本至少 85 分，LLM 提炼成功理由，并保存代码与来源信息。
- **负记忆：** 相邻尝试从崩溃变成成功渲染，或者两个相邻可渲染版本的视觉分至少提升 5 分。LLM 提炼结构化教训，而非直接保存代码差异。

未通过某类门控的轨迹不会生成该类记忆。记忆库从空开始，持续增长，不做淘汰或释义级去重。我们的理解是：这些是局部改善门控，并非通过独立干预识别某条教训的因果作用。

## 论文报告的主要结果

所有文本智能体与视觉审查器使用同一个 GPT-5.5 系列端点。39 条建库任务生成冻结快照；按论文划分、不重叠的 33 条固定探针任务只读使用快照，不回写。人工评分来自其中分层抽样的 25 条任务，而非全部探针任务（§4、附录 H）。

| 条件（表 1） | 人工 Pass@1（%） | 平均反思轮数 ↓ | 平均人工质量（1–5） |
|---|---:|---:|---:|
| 仅 VLM 反思 | 68.5 | 12.2 | 3.41 |
| Manim-code RAG | 83.3 | 11.4 | 3.65 |
| Random EMB | 69.6 | 11.3 | 3.42 |
| EMB@0 | 62.0 | 12.2 | 3.26 |
| EMB@50 | 66.7 | 11.3 | 3.31 |
| EMB@100 | 75.0 | 10.8 | 3.43 |
| EMB@200 | **84.9** | **6.5** | **3.88** |

**Pass@1 是人工“可用”投票占全部个体投票的比例**，不是多数票通过的任务比例。质量指标对五项 Likert 维度和评分者取平均。人工判断针对首次尝试的视频，反思指标则针对收敛过程；不能把首次尝试评测与最终 best-of-N 交付混为一谈。表中仅有点估计，没有种子方差、置信区间或每格独立运行次数，也没有说明头条结果对应哪个种子或是否选取了最好的一次运行。

## 决定收益是否可信的对照实验

- **检索，而不只是多塞上下文。** Manim-code RAG 使用公开文档与社区代码，编码器、索引、检索深度、截断预算与 EMB 相同。Random EMB 保持记录数量、格式和 token 预算，但打乱任务对应关系。这是有用的对照，不是总成本相等的对照：静态基线没有获得自生长的写入/整合回路，也没有匹配建库开销。
- **通道与内容（表 1）。** 去掉正记忆后，Pass@1 为 70.0、反思 12.0 轮；去掉负记忆后为 80.9、11.6 轮，完整系统为 84.9、6.5 轮。去掉正记忆中的代码片段为 75.0 / 10.5 / 3.50；取消负记忆门控为 81.8 / 8.4 / 3.64；两个通道各检索一条为 81.0 / 9.9 / 3.84。这支持通道互补，但消融差距均无不确定性估计。另一个 no-memory 消融为 61.8 / 12.2 / 3.20，不是 EMB@0 或仅 VLM 那一行。
- **谁判断质量？** 54 名研究生盲评，条件、记忆库大小、VLM 分数均不可见。主计划是 175 个视频各三份评分，但附录也描述每视频两或三份评分，并在 153 个三人评分视频上报告一致性。PDF 未完整对齐各条件最终分母。二元可用性投票的 Fleiss’ κ 为 −0.01，完全一致率为 59.4%。连续质量评分的信度同样低：五项 Likert 维度的 ICC 分别为视觉设计 0.24、关键主张覆盖 0.00、视觉稳健性 0.10、动画流程 0.33、首次尝试可用性 −0.09，仅基于 23 个由三人评分的视频（附录 H，第 20 页）。分歧直接聚合，不仲裁。低一致性加上缺少置信区间，使对 RAG 的小幅领先难以解释。
- **奖励模型的偏好风险。** 同一个 GPT-5.5 审查器既指导修改又门控记忆写入，其偏好可能自我强化，所以头条质量改用盲评。在过滤缺失/失败渲染后的 37 个配对视频上，VLM 与人工的 Pearson 相关为 −0.17、Spearman 为 −0.20、Cohen’s κ 为 −0.07（表 9）。换成 Step-3.7-Flash 审查器后为 80.0 / 8.6 / 3.42。这一敏感性对照不能消除共享盲点，也不能证明视觉奖励与人工一致。
- **选择与泄漏。** 默认参数跨条件固定并与运行清单一致（表 13），但论文未说明由哪个数据划分选择，也未报告基线调参/搜索预算。论文描述了论文重叠检查、输入/评测字段隔离验证、探针只读，以及按预训练截止时间分层。截止前后 Pass@1 分别为 74.1% / 80.0%，质量为 3.56 / 3.40（表 14）：方向不一致，不代表证明不存在预训练污染。40 条 cross-test 只用于探索性记忆定性检查，不是量化迁移证据。

## 增益缺失或较小之处

大幅差距来自与空记忆的比较，而非最强静态检索基线。只有 EMB@200 的两项人工指标超过 Manim-code RAG；EMB@50 和 EMB@100 仍低于其 83.3% Pass@1 与 3.65 质量。完整系统为 84.9% / 3.88，Top-1 检索的质量已经接近，为 3.84。没有方差与置信区间，这些是数值差距，不是已证实统计可靠的胜出。

**反思更少不等于延迟更低。** 表 12 报告 EMB@200 每任务 31 分钟，RAG 为 27，Random EMB 为 25，EMB@0 为 19。完整 EMB 的 LLM/VLM token 估计为 36K/20K，RAG 为 38K/23K。这些数字根据输出字符与审查调用估算，没有显式 token 计数。附录 P 将更长渲染时间归于更复杂的场景。每场景预算相同：两次文本重试、两次视觉修改，沙箱墙钟限制 180 秒、CPU 120 秒、内存 4 GB。论文未报告建库总成本或美元费用。

论文没有按领域或任务列出增益，无法判断平均值是否由少数任务驱动。证据限于一个主要模型系列、一个渲染器、五个英语科学领域；没有测试学生学习效果。

## 我们的解读（Our read）

HarnessRSI 评分 **67**，档位 **★★**，证据等级 **retained**。冻结、按论文分离、只读评测，以及通道/门控消融，支持留存经验改善后续动画任务。检索预算部分匹配，但总算力未匹配。论文报告了人工评测、估算的每任务资源、奖励与人工一致性、泄漏防护；没有报告重复运行方差、置信区间、记忆构建总成本，或跨渲染器/模型的量化迁移。低人工一致性和相对强 RAG 的有限优势是核心限制，而不是脚注。这是有用的留存记忆证据，不是已经证明递归改进的改进器。
