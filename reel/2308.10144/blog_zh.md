# ExpeL：智能体把自己的试错整理成一份规则清单——收益有多大，要看你读哪一条对照

*Reel 解读：[arXiv 2308.10144v3](https://arxiv.org/abs/2308.10144v3)（HarnessRSI Daily 评分 72，★★★）。代码：[LeapLabTHU/ExpeL](https://github.com/LeapLabTHU/ExpeL)。*

## 系统改变了自己的什么

ExpeL 从不改动模型权重。任务之间被保留下来的有两样东西：**经验池**（训练任务中的全部轨迹，成功的和失败的）和从中提炼出的**自然语言洞见（insight）清单**。测试时，这两者被写进一个冻结的 gpt-3.5-turbo-0613 ReAct 智能体的提示词里。

## 信号来源与保留/拒绝规则

1. **收集。** 在训练任务上先跑 ReAct，失败则用 Reflexion 重试，最多 Z = 3 次。环境给出的成功/失败信号为每条轨迹打标签。
2. **提炼。** gpt-4-0613 读取同一任务的一对失败/成功轨迹，或一组 L 条成功轨迹（HotpotQA 与 ALFWorld 取 L = 8，WebShop 取 4），用四种操作修改同一份洞见清单：ADD、EDIT、UPVOTE、DOWNVOTE。新洞见的重要度计数从 2 开始；UPVOTE 或 EDIT 加 1，DOWNVOTE 减 1，计数降到 0 即被删除。论文称这一设计用于防范由次优成功轨迹带来的误导性洞见。
3. **使用。** 测试时提示词包含任务、完整的洞见清单，以及与任务最相似的 top-k 条成功轨迹（Faiss、all-mpnet-base-v2；HotpotQA 取 k = 6，ALFWorld 与 WebShop 取 2）。智能体只有一次尝试，不重试。

## 论文报告的主要结果

测试时由 gpt-3.5-turbo-0613 行动；成功率 %（图 5，附标准误；HotpotQA 100 个任务，ALFWorld 134 个，WebShop 100 个；"四折验证"上的均值 ± 标准误）。

| 基准 | ReAct | ExpeL（一次尝试） | ReAct + Reflexion，3 次重试（R3） |
|---|---|---|---|
| HotpotQA | 28 | 39 | 40 |
| ALFWorld | 40 | 59 | 54 |
| WebShop | 35 | 41 | 48 |

表 3 给出了四个单元格的小数：HotpotQA 上 ReAct 为 28.0 ± 1.4，ExpeL 为 39.0 ± 1.7；ALFWorld 上分别为 40.0 ± 0.3 与 59.0 ± 0.3。相对 ReAct，增益在 HotpotQA 为 11‡ 个点，ALFWorld 为 19‡，WebShop 为 6‡（HotpotQA 上 Act 为 29，相对 Act 的增益为 10‡）。Reflexion 一列并非同口径基线：它在测试任务上重试。

**运行次数与方差。** 解码为贪心、温度 0，因此没有重复运行或随机种子；± 值是折与折之间的离散程度。ALFWorld 的 ± 0.3 对 134 个任务的任务池来说很小（按推理相似度检索一行为 ± 2.1；FEVER 上 Act 为 58 ± 0.0）。采用对半划分时，每一折只评测任务池的大约一半，因此上面的任务数是任务池大小，而非每折测试集大小。图 5 中的 Reflexion 线与图 6 的柱子都没有标准误。

## 决定收益是否可信的对照实验

- **洞见与检索（图 5）。** 仅洞见 / 仅检索：HotpotQA 36 / 31，ALFWorld 50 / 55，WebShop 37 / 38。两部分都有贡献，三个基准上完整智能体均最高。
- **洞见的来源（表 3，HotpotQA）。** ReAct 28.0 ± 1.4；人工编写的洞见 32.0 ± 1.1；构造洞见时加入反思 29.0 ± 0.4；用 gpt-3.5-turbo 提炼 32.0 ± 0.4；ExpeL（gpt-4-0613 提炼）39.0 ± 1.7。论文据此认为学出来的洞见优于人工洞见，更强的提炼模型更有利。
- **检索规则（表 3，ALFWorld）。** ReAct 40.0 ± 0.3；随机抽取成功轨迹 42.5 ± 0.8；按推理相似度检索 48.5 ± 2.1；按任务相似度检索（ExpeL）59.0 ± 0.3。
- **经验是否必要（图 6，HotpotQA）。** 仅有初始少样本的 ExpeL 为 27，ReAct 为 28，仅用 ReAct（无重试）收集经验的 ExpeL 为 35，完整 ExpeL 为 39。论文指出，仅从少样本示例中提炼洞见相对 ReAct 没有优势。
- **迁移（表 1）。** 把 HotpotQA 的洞见交由 gpt-4-0613 改写后用于 FEVER（§5.4）：Act 58 ± 0.0，ReAct 63 ± 0.4，不带任务示例的迁移 65 ± 1.7，带任务示例的迁移 70 ± 0.7。Act 与 ReAct 没有得到这种 gpt-4 帮助；65 ± 1.7 对 ReAct 的 63 约为一个标准误。只有一对源—目标任务；迁移智能体使用固定少样本示例，没有检索池。
- **叠加 Reflexion（表 2，ALFWorld，论文称"初步"）。** ReAct + Reflexion 在 R0–R3 为 40.3 / 47.8 / 52.2 / 54.4 %；ExpeL 仅检索为 54.5 / 57.5 / 59.7 / 60.4 %；ExpeL + Reflexion 为 59.0 / 60.4 / 63.4 / 64.2 %。无论有没有洞见，叠加 Reflexion 都有帮助（R3 为 64.2 对 60.4）。
- **经验已匹配，但模型与算力未匹配。** ReAct 与 Reflexion 基线没有训练集经验；最接近的对照是论文的"仅检索"变体，它拥有这些经验（HotpotQA 31，ALFWorld 55，WebShop 38）。gpt-4-0613 洞见层在"仅检索"之上增加 8‡、4‡、3‡ 个点；在 ALFWorld 上，仅检索就已给出相对 ReAct 的 19‡ 个点中的 15‡。基线没有 gpt-4-0613 提炼器，也没有按 token 或算力匹配的对照行。收集与提炼阶段的成本未报告（只给出硬件）。评测时每条轨迹的 token 数（表 6，"每条轨迹的平均计数"）ExpeL 高于 ReAct：HotpotQA 为 4310.06 对 1319.75（约 3.3‡ 倍），ALFWorld 为 2856.7 对 2051.49（1.39‡），WebShop 为 3291.31 对 2575.41（1.28‡）。正文没有说明 L、k、Z 如何选取，也没有报告污染或泄漏检查；任务集沿用 ReAct 与 Reflexion 所用的那些。

## 增益缺失或较小之处

- **HotpotQA 对比 Reflexion。** ReAct + Reflexion 在 R2 与 R3 为 40，ExpeL 一次尝试为 39；论文称之为"持平"。Reflexion 在测试任务上带着环境反馈重试，ExpeL 不重试。
- **WebShop。** ExpeL 为 41，Reflexion 在 R1 即为 43（R3 为 48）；奖励分 0.701，ReAct 为 0.665（表 5）。论文自己也指出仍有改进空间。
- **与标准误同量级的差距。** HotpotQA 仅洞见 36，对完整 ExpeL 39（ExpeL 的标准误 1.7）。若由 gpt-3.5-turbo 提炼洞见，HotpotQA 为 32.0，ReAct 为 28.0，因此 11‡ 个点增益中的大部分依赖 gpt-4-0613 提炼器。
- **ALFWorld 按任务类型（表 5；未给出各类数量）。** "clean" 上 ExpeL 为 74，仅洞见为 87；"cool" 上 67，ReAct 为 71；"heat" 上 43，模仿学习为 74。相对 ReAct，六类中有四类增益很大（put 83 对 50，heat 43 对 13，look 39 对 0，puttwo 29 对 0），clean（74 对 61）较小，cool（67 对 71）为负。
- **措辞。** 图 5 题注称 ExpeL"在所有领域一致优于基线"，并把 ReAct 与 Act 作为基线；这对它们成立（对模仿学习也成立：ALFWorld 37，WebShop 29），而 Reflexion 线不在该题注所指的基线之内。论文写"四折验证"，却描述为训练一半、测试另一半并互换。
- **涌现行为（§5.3）** 是人工检视的个例，因果表述为"可能""或许"，没有给出出现频率。
- **作者自述的局限。** 仅文本观测、使用闭源 API 模型、洞见清单可放入上下文窗口。

## 我们的解读（Our read）

HarnessRSI 评分 **72**，档位 ★★★，证据等级 **retained**：被保留的洞见和轨迹，在同一基准的未见任务上有帮助。论文报告了留出任务、多折均值与标准误、对保留组件的消融，以及一组跨任务迁移（HotpotQA 到 FEVER）；没有报告算力匹配的基线、构建洞见清单的成本和泄漏检查，也没有把改进机制与其他改进器做对比，因此证据止于 retained 级别。就该模式的条件而言，我们的判定认为论文的立意主要落在"无需梯度更新"上，而非更具体的固定假设（S1 为否、F1 为是）；成败对比、显式的增/改/投票维护以及计数归零即删除的规则则判为具备。
