# SEDM：保留一条记忆，与使用这条记忆，是两种决策

*Reel 解读：**SEDM: Selective Self-Evolving Distributed Memory for Agents**，[arXiv 2509.09498v4](https://arxiv.org/abs/2509.09498v4)。HarnessRSI 评分 65，★★，证据等级 retained。未提供代码链接；论文承诺发布代码。*

## 系统改变了自己的什么

SEDM 改变后续智能体可使用的**共享记忆**：哪些经历入库、检索权重与层级、哪些重复项合并、哪些模式被蒸馏或淘汰。任务智能体为 gpt-4o-mini；系统不是改写智能体源代码。接收端的校准记忆门控 CMG **确实训练模型权重**：通过 LoRA 训练 Qwen3-4B，决定是否把检索到的记忆展示给任务智能体。不能把记忆保留回路与这个单独训练的门控混为一谈。

## 迭代回路与保留/拒绝规则

1. 将一次任务封装为自包含执行上下文 SCEC：输入、输出、工具调用摘要、随机种子与配置哈希；从中提取候选记忆。
2. 分别带着和不带候选记忆重放任务。奖励增益减去延迟与 token 惩罚达到阈值才准入。**表 1–3 使用原始配置：在记忆自己的来源任务上测试它。** 作者明确指出，这可能高估效用。
3. 更严格的 LoCoMo 流程改为在独立准入对话中选三个相似任务，每个实验臂运行三次。阈值和成本惩罚均为零，因此无害的平局也可保留。先过滤来源任务未解决的候选，以及含被测任务参考答案的候选。拒绝项保留审计记录，但不参与检索。
4. 控制器按相关性与实测效用排序，定期及运行结束时更新权重，在短期、情景、长期层级间升降，合并近重复项、蒸馏重复模式、隔离有害项并衰减闲置项。实体抽象会生成与具体记忆并存的通用版本。
5. 对新问题，CMG 读取问题与检索记忆集合，预测 USE 和 SKIP 的成功概率；只有校准后的概率增益超过记忆长度成本惩罚才注入。训练使用成对结果，**包括平局**，而非只学哪种动作获胜。

**“分布式”具体体现在哪里？** 不同智能体的经历进入逻辑共享记忆；SCEC 可交给独立工作节点重放，回传聚合统计、完整性哈希和版本戳。论文描述了共享控制器如何合并内容，但没有明确副本一致性协议、逐轮同步安排或实测网络/同步成本。两组 CMG 评测都在评测前冻结记忆，并未检验持续同步、共同进化的智能体群体。

## 主要结果：三种协议必须分开读

**原始记忆保留实验，不含 CMG（表 1–3）。** LoCoMo 开放域 F1 为 **47.5 对 32.4**，该列最强基线为 G-Memory；论文报告提升 15.1 点，但不是 LoCoMo 全面胜出。FEVER 准确率为 **66 对 62**（G-Memory），无记忆为 57；HotpotQA 精确匹配为 **39 对 38**，无记忆为 34。FEVER 提示 token 总量为 2.47M 对 3.62M，HotpotQA 为 3.88M 对 4.63M，论文分别报告节省 32% 和 16%。这些表未说明重复运行均值、种子或置信区间，也未按独立准入协议重跑。

**受控的接收端门控实验，HotpotQA（表 4）。** 在 489 条留出问题、种子 42 上，验证集选出的 CMG 成功率为 **0.329 [0.288, 0.372]**，始终使用记忆为 **0.333 [0.292, 0.376]**，无记忆为 **0.249 [0.213, 0.286]**。CMG 在 69% 的问题上注入记忆，任务智能体输入为 **3,047 对 3,736** tokens，节省 18%。这支持质量–成本权衡，不构成准确率显著胜过始终使用的证据。这里成功指 token F1 ≥ 0.5，**不是**上一组实验的精确匹配。

**独立准入加 CMG，LoCoMo（表 5）。** 仅准入记忆下，CMG、始终使用、无记忆的成功率为 **0.556 / 0.539 / 0.544**；CMG 输入 2,263 tokens，始终使用为 2,790，论文报告节省 19%。加入控制器的记忆下，对应成功率为 **0.546 / 0.518 / 0.534**，输入为 1,915 对 2,781，节省 31%。CMG 行是三个门控训练种子的均值。测试仅为**一个对话的 193 条问题**，作者称单项差异处于这一对话的噪声范围。成功判据是 SBERT 相似度 ≥ 0.7。两套记忆及其无记忆锚点来自独立运行，不能直接当作配对控制器消融。

## 决定收益意味着什么的对照

- **与记忆基线比较的保留消融（表 2）。** FEVER 从 G-Memory 62，到仅准入 64，再到准入加控制器 66；HotpotQA 则为 38 → 37 → 39，仅准入反而更差。这两个任务对 G-Memory 使用相同记忆预算，但不等于总执行/优化成本相同。LoCoMo 的部分基线取自既有工作，记忆预算可能不同；基线调参预算，以及原始实验默认参数在哪个划分上选出，均未报告。
- **门控共享记忆与执行结果（表 4、附录 B）。** 所有策略均在同一批成对任务执行上计分，学习型门控共享骨干和训练配方。相似度门控、获胜标签门控都退化为始终注入，得分 0.333。CoT 为 0.262，每次决策 3.09 秒，CMG 为 0.24 秒；但 CoT 是**零样本复现**，不是原始训练检查点，且 GPU 负载影响计时。Oracle 只是上界诊断，不是可部署基线。
- **选择流程与种子很重要（表 6）。** 门控检查点按验证损失选择，成本价格与相似度阈值也用验证集选择；温度另用校准集拟合。固定价格零时，三个种子的校准 CMG 为 **0.326 ± 0.003**，原始门控为 **0.324 ± 0.017**；若每个种子各自使用验证集选出的价格，则为 **0.318 ± 0.015**。表 4 的 0.329 是种子 42，而非多种子均值。受控实验中的其他门控只用种子 42，完整超参数搜索预算未报告。
- **有迁移，但未隔离抽象的贡献（表 3）。** FEVER 记忆迁移到 HotpotQA 得到 EM 41，高于域内记忆的 39；LoCoMo 记忆迁移到 HotpotQA 为 34，与无记忆持平。全部迁移运行都开启知识扩散，没有关闭扩散的对照。该表整体 LoCoMo F1 不应直接与表 1 的分题型得分比较。

## 记忆内容、泄漏边界与成本

受控 HotpotQA 实验将开发集分成记忆构建、门控训练各 2,962 题，验证、校准各 496 题，测试 489 题。每条记忆包含构建问题、经验证答案及**金标准支持句**，每次取最相似的五条经历。哈希清单与拒绝检查保障记忆只来自构建划分。作者称金标准证据构建是乐观设定；记忆与后续问题仍可能共享实体或事实，未报告实体互斥或近亲任务审计。两种动作还共享由全部开发集段落构建的冻结工具语料；普通工具检索证据不等同于把测试经历复制进记忆库。

完整 LoCoMo 流程以对话 0 构建记忆，1 做准入，3–7 训练门控，8 验证，9 校准，2 测试。因此准入与最终测试分离，且报告了答案包含过滤。这些保障强于原始来源任务准入，但不能追溯证明表 1–3 同样严格。

附录 E 报告成对数据收集约用 **24.7M 输入和 1.3M 输出 tokens**，约 **US$4.5**。学习型门控在一张 A40 上训练三轮。论文未给完整的记忆构建、准入重放、控制器合并、同步以及 GPU 门控训练成本账本；每题任务智能体输入节省不等于全生命周期节省。

## 增益缺失或狭窄之处

- LoCoMo 的最大收益集中于**开放域**。单跳为 51.7 对 G-Memory 53.5，多跳 33.5 对 34.6，时序 12.1 对 A-Mem 45.9，对抗题 12.1 对 LoCoMo 基线 69.2（表 1）。
- 始终注入独立准入的 SEDM 记忆并未提高 LoCoMo 成功率：仅准入为 0.539 对 0.544，加控制器为 0.518 对 0.534（表 5）。门控恢复了观测收益，但单个对话与重叠不确定性限制结论。
- 受控 HotpotQA 的准确率与始终使用相当，并非更高。按问题 bootstrap 的区间不代表独立记忆构建重复实验，也不证明跨模型稳健性。原始保留/迁移表没有报告方差；表 5 报告三种子均值，但未给每行置信区间。
- 策略笔记先导实验中，种子 42 的 CMG 与无记忆同为 0.275，但另一种子仅 0.255（表 9），并非总能恢复。只评测了一种任务智能体和一种门控骨干。

## 我们的解读（Our read）

HarnessRSI **65 · ★★ · retained**。证据支持按执行结果准入记忆，以及通过接收端门控降低任务智能体上下文成本。论文报告了保留消融、跨域记忆迁移、部分记忆预算匹配、门控种子方差、划分/哈希检查及答案包含过滤；未建立完整算力匹配、原始表格的稳健不确定性、持续进化的分布式运行或完整记忆构建/同步成本。

存档判断将留出与预算证据标为 partial，泄漏防护标为 untested。完整 PDF 确实描述了具体保障，我们在 SOURCE.md 注明，而不把标签解释成“没有检查”。最强的留出实验还使用了冻结记忆上的单独训练门控，并未证明改进器自身的递归改进。
