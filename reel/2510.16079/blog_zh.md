# EvolveR：保留策略经验确实有用，但收益不全来自自蒸馏

*Reel 解读：[arXiv 2510.16079v3](https://arxiv.org/abs/2510.16079v3)，完整标题 **EvolveR: Self-Evolving LLM Agents through an Experience-Driven Lifecycle**（HarnessRSI Daily 评分 65，★★）。代码：[Edaizi/EvolveR](https://github.com/Edaizi/EvolveR)。*

## 系统改变了自己的什么

EvolveR 同时改变**外部经验库和智能体的策略权重**，并不是权重冻结的纯记忆方法。其 harness 层面留存物是可检索的策略原则库：每条原则有简短自然语言描述、主语—谓语—宾语三元组、关联的来源轨迹，以及历史使用/成功计数。成功轨迹产生指导原则，失败轨迹产生警示原则。离线阶段冻结参数，由策略模型自己蒸馏原则；在线阶段收集的轨迹随后用于 GRPO 策略训练。

解题时，智能体可交替推理、搜索经验库、搜索外部事实知识库和回答。每次经验搜索返回前三条原则。默认情况下，检索到的经验和外部资料仅作上下文，其 token 的训练损失被屏蔽，并非直接模仿的训练目标。

## 迭代回路与保留/拒绝规则

1. 智能体借助知识搜索和经验检索完成在线交互，收集轨迹。
2. 冻结策略参数，从成功和失败轨迹中自蒸馏原则。
3. 对同一问题产生的语义等价原则去重。候选与旧库通过嵌入相似度预筛（阈值 **0.85**），再由策略模型作是/否语义等价判断。新颖原则新增为条目；重复原则的轨迹并入已有条目。
4. 用 **s(p) = (成功次数 + 1) / (使用次数 + 2)** 记录历史效用，定期删除分数低于 **0.3** 的原则。
5. 用 GRPO 更新策略；奖励包含与标准答案精确匹配的正确性信号，以及约束推理、搜索动作的格式奖励，然后重复上述生命周期。

这是历史效用保留规则，不是在验证集上比较候选与当前版本的验收测试。论文没有进一步说明多条原则共同被检索时，如何更细粒度地归因成功。生命周期还包含教师辅助冷启动：GPT-4o 根据约 700 条 NQ/HotpotQA 训练题、相关文档和标准答案构造轨迹。因此，“自蒸馏”指后续原则生成者，不代表整个训练完全不用教师。

## 论文报告的主要结果

表 1 使用标准化 Exact Match（EM），报告七个基准的平均分：

| 模型 | EvolveR | 基线中的最高平均分 |
|---|---:|---:|
| Qwen2.5-3B | 0.382 | 0.325（Search-R1-instruct） |
| Qwen2.5-7B | 0.417 | 0.385（Search-R1-instruct） |

论文称经验库由 **NQ 和 HotpotQA 的训练划分**构建；TriviaQA、PopQA、2WikiMultiHopQA、Musique、Bamboogle 则为只用于评测的域外数据集。论文未明确给出各评测划分的具体标识/大小、表 1 对应的检查点，以及每格的随机种子/运行次数。这些是**跨基准平均值，而不是论文报告的多种子均值**；主要比较没有方差或置信区间。

收益分布并不均匀。7B 相对 Search-R1-instruct 的较大提升在 **NQ（0.462 对 0.393）**和 **PopQA（0.473 对 0.397）**；HotpotQA 为 0.411 对 0.370，TriviaQA 只有 0.620 对 0.610。3B 对各列最强基线的较明显增益在 2WikiMultiHopQA（0.381 对 0.319）和 HotpotQA（0.373 对 0.324），Bamboogle 只有 0.328 对 0.320。收益涉及多个任务，但平均分不意味着各任务等幅受益。

## 决定收益是否可信的对照实验

- **同一训练策略，只在评测时关闭经验检索（表 3）。** 3B 平均分从 **0.382 降至 0.340**，这是留存经验库在权重之外仍起作用的最清楚证据。单基准降幅最大的是 Bamboogle：0.328 降到 0.240；TriviaQA 仅从 0.584 降到 0.569。0.5B 从 0.150 降到 0.078，1.5B 从 0.270 降到 0.123。这检验的是经过经验训练的策略对记忆的依赖，不代表其他基线获得同一记忆后不能同样受益。
- **组件归因（表 4）。** 3B：既无记忆也无 RL 为 0.134；不做原则蒸馏/检索、仅 RL 为 0.325；蒸馏加检索、不做 RL 为 0.357；经验驱动 RL 训练、评测关闭检索为 0.340；完整系统为 0.382。0.325 与 0.340 是不同条件，不能混称为同一个“仅 RL”分数。
- **同一经验机制，不同原则生成者（表 2）。** GPT-4o-mini 教师蒸馏在 0.5B（**0.220 对 0.150**）和 1.5B（**0.290 对 0.270**）上优于自蒸馏。3B 自蒸馏平均分较高（**0.382 对 0.370**），但并非所有任务都胜：教师在 **2WikiMultiHopQA 为 0.437**，自蒸馏为 0.381。作者的“认知对齐”解释是一种解读，不是单独识别了原因的因果实验。
- **使用同一批成功在线轨迹的 SFT 与 GRPO（表 8）。** SFT 为 0.357，GRPO 为 0.382；GRPO 还利用失败轨迹。TriviaQA 同为 0.584，最大差异在 Bamboogle：0.248 对 0.328。论文给出 SFT 训练设置，但没有称算力匹配。
- **策展诊断不等于剪枝的直接因果消融。** 对 100 条原则的人工标注中，高分层有 82% 理想原则、8% 错误/误导原则，低分层分别为 26% 和 24%（表 6）。这是不同分数层之间的比较，不是剪枝前后实验。1.5B 的剪枝阈值扫描中，默认 0.3 得到 0.270，阈值 0.9 得到 0.276（表 9）。论文未说明默认值、其他超参数或检查点由哪个划分选择，也未报告基线的调参搜索预算。
- **可比经验与算力。** 教师蒸馏变体获得同一经验机制，SFT 对照获得同一批成功轨迹；但没有报告给表 1 的 Search-R1 等主基线配置 EvolveR 的策展原则/轨迹库，也没有原始轨迹库对照或经验积累预算匹配比较。3B 完整生命周期报告为 **八张 A100（80GB）上运行 39.4 小时**，包括冷启动 SFT 和 GRPO。离线策展、教师生成成本未单列，基线训练时间/token 预算未提供。约 14,000 条原则时查询耗时 0.06 秒，这是检索延迟，不是积累经验库的成本。
- **泄漏边界。** 论文说明训练划分用于构库、域外数据用于评测，但全文附录未报告题目/答案或近重复重叠审计，也未明确规定评测轨迹是否禁止写回后续记忆。扩容实验从六个未具名基准中随机抽取 10% 验证子集（表 7），其与主要评测及默认值/检查点选择的关系未说明。因此，仅凭论文无法排除训练与评测存在关联问题。这是协议边界未解，不是评测题已进入经验库的证据。

## 增益缺失或较小之处

- **3B 并非逐项领先。** TriviaQA 为 0.584，Search-R1-base 为 0.587；PopQA 为 0.434，该基线为 0.435。Bamboogle 对 Search-o1 的优势（0.328 对 0.320）很小，未报告不确定性。
- **7B 在 2WikiMultiHopQA 落后。** EvolveR 为 0.395，Search-R1-instruct 为 0.414。TriviaQA 的小幅优势也无法对照运行噪声判断，因为未报告方差。
- **自蒸馏依赖模型规模。** 两个较小规模的平均分都低于教师蒸馏；3B 上有利的结果不能证明其普遍优于教师。
- **经验积累更多并非单调更好。** 扩容验证子集上，45,083 条原则对应 EM 0.410，49,934 条对应 0.387（表 7）。由于记忆和策略同时变化，我们的解读是这是一条联合训练轨迹，而不是单独操纵库大小的实验。
- **直接训练检索到的经验 token 没提高平均分。** 不屏蔽其损失得到 0.371，默认方案为 0.382（表 11）；PopQA 则略微反向，为 0.435 对 0.434。

## 我们的解读（Our read）

HarnessRSI 评分 **65**，档位 **★★**，证据等级 **retained**。记录肯定了跨任务评测、检索消融以及自蒸馏/教师蒸馏比较。同一训练策略在关闭经验库后准确率下降，因此留存记忆证据比没有消融的头条结果更强。但整体收益耦合了记忆与权重更新，尚未证明经验策展器本身在可比预算下成为了更好的改进器。后期原则分数只在仍留存的条目中测量（表 10），不是与冻结改进器的对照。

已存判断把优化器成本留为不明确；完整 v3 PDF 实际报告了 39.4 小时生命周期时间与检索延迟，我们注明这一修正，不修改评分或判断文件。主要剩余限制是运行方差未报告、经验/训练预算未匹配，以及划分、选择和污染边界说明不完整。
