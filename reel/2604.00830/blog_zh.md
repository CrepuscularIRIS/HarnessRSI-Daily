# Meta-TTL：学习“如何自我改进”的提示词，而不是手写——方向一致，但能衡量幅度的对照偏少

*Reel 解读：[arXiv 2604.00830v4](https://arxiv.org/abs/2604.00830v4)（Zhanzhi Lou、Hui Chen、Yibo Li、Qian Wang、Bryan Hooi；新加坡国立大学）。HarnessRSI Daily 评分 69，★★。代码：[zzzlou/meta-ttl](https://github.com/zzzlou/meta-ttl)。*

## 系统改变了自己的什么

测试时学习（TTL）中，智能体对同一任务连续尝试多个回合，并在回合之间改写自己的上下文。Meta-TTL 不动**执行者（actor）**（冻结的 Gemini-3-Flash），而是把“如何改写执行者系统提示词”的过程当作可学习对象。该过程是一份自然语言**元提示词（meta-prompt）**ϕ，由另一个**元智能体（meta-agent）**读取（主实验为 GPT-5）。每个回合结束后，元智能体阅读轨迹历史，写出执行者下一回合的系统提示词。一次会话在 Jericho 上有 6 个回合，在 WebArena-Lite 与 τ²-bench 上有 3 个回合，用 W-AUC 评分：这是对各回合分数的归一化加权平均，后面的回合权重更大（第 k 回合权重为 k）。

## 元训练回路与保留/拒绝规则

1. 维护一份**专家**元提示词 ϕ⋆，由种子元提示词初始化。
2. 采样一个训练任务，用 ϕ⋆ 跑完整的 TTL 会话。
3. 两阶段反思：先从会话中提取任务相关事实，再结合会话、事实和 ϕ⋆ 写出修订后的候选元提示词。
4. 用专家与候选**两者**在一组验证任务上各跑 TTL 会话，按 W-AUC 评分。
5. 把每个任务的 W-AUC 对该任务的历史得分做 z 分数归一化，再对任务取“候选减专家”的平均差，即**平衡改进分（BIS）**。只有 BIS 为正，候选才替换专家。

元训练共 12–15 轮迭代、205–350 次 TTL 会话，每个基准约 $30–70 的 API 费用（一次性成本，无需 GPU）。最终元提示词被冻结，用于未见任务。执行者权重没有任何改变，被保留下来的是一份文本。搜索是单一在位者加贪心接受规则，而非种群。

## 论文报告的主要结果

主实验的执行者均为 Gemini-3-Flash；需要额外适配 LLM 的基线同样使用 GPT-5，即与 Meta-TTL 的元智能体同一模型。下面是平均 W-AUC，Meta-TTL 对该列最强基线（表 1–3）：

| 基准 | Meta-TTL | 最强基线 |
|---|---|---|
| Jericho 域内游戏（5 次运行） | 0.396 | 0.323（EvoTest），+23% |
| Jericho 域外游戏 | 0.414 | 0.325（EvoTest），+27% |
| WebArena-Lite 域内（3 次运行） | 0.693 | 0.619（Memory Agent），+12% |
| WebArena-Lite 域外 | 0.766 | 0.728（TextGrad），+5% |
| τ²-bench Airline | 0.717 | 0.650（TextGrad），+10% |
| τ²-bench Retail | 0.700 | 0.633（Memory Agent），+11% |
| τ²-bench Telecom（域外） | 0.583 | 0.525（Reflexion），+11% |

基线包括 Static、Reflexion、Memory Agent、AWM、TextGrad、EvoPrompt、EvoTest 以及 Naive 元智能体。论文给出了 Jericho（5 次）和 WebArena-Lite（3 次）的重复运行次数，τ²-bench 未说明；性能表（表 1–5、7–8）只有均值，没有标准差；波动只出现在图 3（Jericho，5 次运行的标准误）和表 6 的墙钟时间（± 标准差）中。

## 决定收益是否可信的对照实验

- **Naive 元智能体（架构与模型相同，但自我改进策略未优化）。** 论文把它列为基线（并非放在消融一节）；由于只有自我改进策略不同，它最接近“有无元训练”的对照。W-AUC：Jericho 为 0.215（域内）/ 0.286（域外），对应 Meta-TTL 的 0.396 / 0.414；WebArena-Lite 为 0.567 / 0.722，对应 0.693 / 0.766；τ²-bench 为 0.633 / 0.558 / 0.433，对应 0.717 / 0.700 / 0.583。在 Jericho 域内，Naive 元智能体的平均得分（55.01）并不高于 Static（55.61），其 W-AUC（0.215）与 Static 的 0.195 接近。论文没有说明 Naive 元智能体就是种子元提示词。
- **同一任务上的其他优化器（表 5，Jericho W-AUC，Qwen3-4B 元智能体，Gemini-3-Flash 执行者）。** 用 GRPO（1,920 次 rollout）或 GEPA 外循环训练元智能体，对比 Meta-TTL 外循环（350 次 rollout）。域内平均：未训练 0.146，GRPO 0.150，GEPA 0.152，Meta-TTL 0.164；域外平均：0.168、0.174、0.198、0.232。对于 GEPA 域外较弱，论文给出的可能解释是其候选选择机制保留了针对单个任务的专门化提示词，并补充说这“也与我们的发现一致”，即 GEPA 产生的提示词包含大量任务特定的事实和解法（附录 A.4 的 GEPA 提示词含有 Detective 的具体内容，如“330/360”）。这里的三个域内游戏就是元训练游戏。论文未说明 GEPA 的 rollout 预算，也未说明该表的运行次数。
- **更新参数的 TTL（表 4，Jericho W-AUC，Qwen3-8B 执行者，K = 3 个回合，每回合最多 30 步；设置与主表不同，0.182 不能与 0.396 比较）。** 这里的 Meta-TTL 用 Qwen3-8B 执行者和 Qwen3-8B 元智能体，运行“主实验中学到的元提示词”（该提示词用 GPT-5 元智能体和 Gemini 执行者元训练，之后直接复用，并未在 Qwen3-8B 上重新元训练）。Meta-TTL 为 0.182（域内）/ 0.201（域外），Online GRPO 0.118 / 0.114，Online SFT 0.116 / 0.092，SFT+MAML 0.122 / 0.157，Static 0.084 / 0.094。域内游戏就是元训练游戏，SFT+MAML 的初始化也是在这些游戏上元学习的（15 个元步，2×H200）。论文未说明该表的运行次数。
- **更换元智能体骨干（附录 D，GLM-5.3-Flash）。** 只覆盖 Jericho 与 WebArena-Lite（不含 τ²-bench）。用该骨干重新元训练；在表 7 与表 8 的每一列中 Meta-TTL 都最好，但对比的基线只有三个（Naive、AWM、EvoTest）。Jericho 域外平均得分几乎持平（0.343 对 EvoTest 的 0.334），且这里 Meta-TTL 的 Jericho W-AUC（域内 0.379、域外 0.371）低于主表的 0.396 与 0.414（元智能体不同）。
- **测试时成本（表 6，Jericho，3 次运行）。** Meta-TTL：墙钟 860.9 ± 66.2 秒，364k token，5 次适配 LLM 调用；Static 为 593.2 秒、196k；EvoTest 为 759.1 秒、181k。论文称其与提示词优化类基线“相当”。

未做或未报告：与主要基线的算力匹配比较（基线没有元训练预算，那 $30–70 并未给到它们，其调参预算也未报告）；任何性能表单元（表 1–5、7–8）的标准差；重复的元训练运行（附录 A 每个基准只展示一份学到的元提示词）；验证集与评测集的规模。

## 增益缺失或较小之处

- **Jericho 域内由一款游戏主导，并且这是元训练集。** 相对 EvoTest，W-AUC 差距在 Detective 上为 0.162‡，Zork 1 为 0.011‡，Temple 为 0.046‡。论文写明 Jericho 的“域内评测使用元训练游戏”，所以这三款游戏并未留出；留出的 Jericho 结果是域外各行。
- **与该列最强基线持平或接近。** Jericho 域外 Zork 3：0.427 对 EvoTest 的 0.423（差 0.004‡；Balances 与 Library 上，与最强基线（两处均为 Naive 元智能体）的差距为 0.092‡ 与 0.113‡）。WebArena-Lite GitLab 的 W-AUC：0.883，与 AWM 相同。WebArena-Lite Shopping Admin：0.760 对 0.749。τ²-bench Retail 的平均得分：0.633，与 Reflexion 相同。论文没有给置信区间，这些单元无法与噪声区分。
- **与 GEPA 在一款域内游戏上。** 在 Jericho Temple（表 5）上，Meta-TTL 外循环为 0.129，与未训练的元智能体相同，低于 GEPA 的 0.154。表 5 的域内游戏同样是元训练游戏。
- **与更新参数的基线在个别域外游戏上（表 4）。** SFT+MAML 在 Zork 3 上为 0.405，Meta-TTL 为 0.238；Balances 上 Online GRPO 为 0.147，Meta-TTL 为 0.131。
- **Jericho 域外 Zork 3 的平均得分**，Meta-TTL 与 EvoTest 均为 2.87。
- **没有局限性章节。** 论文没有该章节，也没有报告污染或泄漏检验。

## 我们的解读（Our read）

HarnessRSI 评分 **69**，档位 ★★，证据等级 **improver**：自我改进策略本身被优化，并与 Naive 元智能体、其他优化器做了对比。论文报告了在未见域上的留出评测（部分：Jericho 域内用的是训练游戏）、跨域迁移、优化器成本、Naive 元智能体基线、RL 与 GEPA 外循环对比，以及第二种元智能体骨干。论文没有报告各单元的标准差、与主要基线的算力匹配比较、重复的元训练运行、评测集规模，或泄漏检验。论文内部的几处不一致：摘要的“域内最高 23%、域外最高 27%”指 W-AUC，而表 1 域外平均得分是 +33%（10.61 对 7.99）；算法 2 把接受裕度 δ 和第 0 回合基线结果列为输入，但接受规则只是比较平均 z 分数；表 7–8 的平均得分是归一化尺度，与表 1 的原始游戏得分不同。可以把头条数字读作：在 7 列、8 个基线上方向一致，但每个单元的幅度没有经过噪声检验。
