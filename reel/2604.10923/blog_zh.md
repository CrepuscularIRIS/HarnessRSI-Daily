# Mem²Evolve：让两类记忆共同演化——可复用的能力，以及创造能力的经验

*Reel 解读：[arXiv 2604.10923v1](https://arxiv.org/abs/2604.10923v1)（HarnessRSI Daily 评分 65，★★）。本次 Reel 未提供代码链接。*

## 系统改变了自己的什么

Mem²Evolve 保留的是**两类互相促进的记忆**，不是重新训练的模型权重。**资产记忆（Asset Memory）**保存可执行的 MCP 工具与专家智能体规格，包括角色、专长、行为建议和可用工具。**经验记忆（Experience Memory）**保存从成功与失败中提炼的实现方法和执行策略。经验指导资产创建与任务执行，新资产又产生可供蒸馏的新轨迹。“协同演化”指能力与经验的互动，不是策略权重更新。

## 迭代回路与保留/拒绝规则

1. 规划子任务，从资产记忆中检索最匹配的专家与相关工具；若相似度未超过阈值，利用相关经验与网络文档创建缺失能力。
2. 通过 ReAct 执行并汇总答案。LLM 评判器读取任务、轨迹与答案，给出成功/失败及评语。方法明确假设后向演化阶段拿不到真实标签。
3. 新资产在任务成功、且通过 LLM 根据评语合成的全部测试后入库；否则根据评语和失败测试修正，再生成测试，直到通过。论文没有指定重试上限、最终丢弃规则或独立留出的回归测试。这是局部入库检查，不是依据后续基准增益选优。
4. 将成功和失败轨迹中的教训追加到经验记忆。论文没有给这些条目另设拒绝规则。模板保留任务上下文和结果，工具经验条目还包含完整实现代码。

## 决定收益是否可信的对照实验

- **组件消融（表 3、表 6）。** 完整系统 70.24；去掉工具创建 59.96；去掉专家创建 68.52；去掉工具经验记忆 67.11；去掉智能体经验记忆 65.51。这支持两类记忆和创建机制的贡献，但没有报告方差或算力匹配的替代方案。
- **收益集中在哪里（表 6）。** 去掉工具创建，GAIA 从 76.31 降到 21.69，AIME24 从 76.70 降到 66.67，AIME25 从 73.33 降到 60.00；ALFWorld 却只有 94.31 到 94.10，WebShop 为 39.20 到 39.05。工具经验记忆也主要帮助 GAIA/数学：GAIA 完整系统 76.31，去掉后 67.47；ALFWorld 为 94.31 对 94.25，WebShop 为 39.20 对 39.15。智能体经验记忆的作用分布不同：TravelPlanner 完整系统 59.25，去掉后 49.36；ALFWorld 为 94.31 对 88.06。平均收益并不意味着处处同样有效。
- **经验指导生成（表 4）。** 工具首次验证通过率平均从 53.1% 升至 72.4%，平均修正轮数从 1.01 降至 0.48。GAIA 首次通过率为 32.7% 对 51.0%，AIME24 为 64.9% 对 83.8%，AIME25 为 61.8% 对 82.4%。这些平均值没有报告不确定性或工具生成样本数。调试轮数减少只是效率代理指标，不是端到端成本测量。
- **留存记忆评测（§5.3、图 3）。** 主表从只有网页搜索、没有既有记忆的状态开始。另一个同任务实验先在基准子集上积累记忆（图 3 图例为 25%‡ 或 50%‡），再评测剩余题目；作者报告增益及边际递减。剩余集合大小、样本/分组划分细节，以及评测时是否冻结记忆更新均未说明。
- **跨任务复用（§5.4、图 4）。** 用 GAIA 记忆初始化另外七个基准，优于无初始记忆，效果被描述为接近 25% 同域初始化。这只涉及一个来源基准、同一报告骨干模型，不是跨模型迁移。没有单独匹配记忆积累预算，也没有误差条。
- **基线能力与调参。** 论文称经验中心框架与 Mem²Evolve 从最小网页搜索配置起步；工具生成型基线也能创建工具。这不意味着朴素基线拥有统一的工具访问条件：Direct 明确不使用外部工具，CoT 是否可搜索未说明，ReAct 则允许网页搜索。Alita 并非没有经验：附录 B.1 明确描述其 Promptist 与 Experience Pool，并说明由于官方代码不可用，实验采用 OpenAlita。没有将 Mem²Evolve 相同双记忆/入库循环加给基线的受控比较。检索默认参数具体数值、超参数/默认值由哪个划分选择、基线调参预算均未报告，不能由此推断基线被削弱。
- **泄漏与成本。** 评判器不看真实标签，不等于记忆无泄漏：任务上下文、结果和实现可能被保留，子集与剩余集仍可能包含同基准近亲题。通读附录未找到重叠/近重复或网页搜索污染审计。这是未解决的风险，不是已发生泄漏的证据。论文未量化 token、费用、墙钟时间，以及记忆积累/存储增长成本；没有算力匹配行。

## 增益缺失或较小之处

HotpotQA 与 AFLOW 同为 **60.80**。2Wiki 的 **82.00 对 81.80**、TravelPlanner 的 **59.25 对 59.14** 差距很小，且没有不确定性估计，可靠程度仍不明确。相对各列最强基线的较大差距在数学和 GAIA；工具创建消融的损失也主要来自这些基准。所有头条对比仅使用一个报告骨干模型。表 5 的完整测试规模分别为 GAIA 166、ALFWorld 134、两个问答各 500、两套 AIME 各 30、TravelPlanner 1,000、WebShop 251；它们不是初始记忆实验中剩余集合的大小。
