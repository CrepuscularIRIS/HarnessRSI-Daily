# SkillLens：技能能改善智能体，但更好的技能仍可能不如不用技能

*Reel 解读：[arXiv 2605.23899v1](https://arxiv.org/abs/2605.23899v1)，**From Raw Experience to Skill Consumption: A Systematic Study of Model-Generated Agent Skills**（从原始经验到技能消费：模型生成智能体技能的系统性研究）。HarnessRSI Daily 评分 **65**，★★，证据等级 **retained**。代码：[microsoft/SkillLens](https://github.com/microsoft/SkillLens)（仓库链接来自我们的榜单；PDF 链接为 aka.ms/SkillLens）。*

## 系统改变了自己的什么

被保留的是**领域级流程技能**，而非模型权重。目标智能体先生成自身的成功与失败执行轨迹；提取模型将轨迹、结果和奖励压缩为技能；随后，同一目标模型在新任务上从系统提示词中读取该技能。研究区分了**提取**有用建议与**消费**建议的能力。主实验中，每个目标—提取器—领域组合只有一个技能，不是从大型技能库检索。

## 迭代回路与保留/拒绝规则

1. 在经验生成划分上多轮运行目标智能体，收集其自身轨迹。
2. 每条轨迹最多提取 **3** 条成功或失败模式。提示词要求可迁移，删除任务特定的文件名、标识符、错误信息和 API 调用；没有有用模式时允许返回空列表。
3. 每 **10** 组模式做一次合并，由提取器自行去重、泛化，并删除含糊或低价值模式。
4. 合成为一个不超过 **3000 字符**的技能。强制检查结构和长度；超长则缩短重试。
5. 将技能直接写入同一目标模型的系统提示词，在相同测试集上与不带技能的目标模型比较。

**论文没有报告基于下游分数的采纳门槛。** 内容上的拒绝依赖提取与合并提示词，另有结构校验，并不是先确认最终技能提升效用才保留。会造成损害的技能同样进入评测。这是提取器辅助的单步更新，不是能无限自我改善的部署回路证据。

## 决定收益是否可信的对照实验

- **经验与测试分离。** 经验/测试按 **1:1** 分配。有官方训练划分时从中抽取经验任务，否则使用固定种子随机划分；不同模型组合共用划分。PDF 没有提供各领域任务数、具体经验池大小或划分种子的值。这是同领域留出任务，不是已经证明跨领域技能迁移。
- **同一技能，不同消费者。** 第 5.3 节固定 GPT-5.4-mini 为提取器，将分别从 GPT-5.4 和 Qwen3.5-9B 经验中得到的两个 SpreadsheetBench 技能提供给全部六个目标。强经验池技能改善所有目标，从 Gemini-3.1-Pro 的 **+1.8** 到 Qwen3.5-35B 的 **+9.5**；弱经验池技能在 GPT-5.4 上造成 **−2.0**。这个固定文本的对照补充了表 1——后者不仅消费者变化，经验来源也随之变化。
- **经验构成与文本格式。** 第 5.1 节固定提取器，在三个领域、三个目标上改变成功/失败比例，最优混合依赖领域。附录 C 将技能改写为四种格式、检查语义保留，并各评测三轮。未检测到格式效应（**全部 p > 0.34**）；该对照中六个目标有五个呈现显著提取器效应。表 8 包含 GPT-5.2、GPT-5.4-nano，模型名单与表 1 不同；其中的轮次噪声统计不是主结果矩阵的逐格不确定性区间。
- **裁判改善不是独立验证。** GPT-5.4 对效用差超过 **0.5 个百分点**的 **151** 对技能进行判断，每对九票并随机化展示顺序。效用导向标准将准确率从 **46.4% 提高至 73.8%，但评估的仍是同一批技能对**。标准来自主矩阵的高差距技能对，又按效用筛选；没有描述独立的标准开发/测试划分。我们的解读：这是有用的诊断反馈，但不是通用技能质量裁判在未接触测试集上的效果估计。后续元技能实验同样没有报告专为标准开发隔离出的基准留出集。
- **基线访问权限与预算。** 无技能基线是同一目标、同一测试集、不带提取技能，而不是获得同等检索库的基线。原始、合理性指导、效用指导三种提取均使用统一框架；主协议直接注入一个技能，没有检索。论文没有报告算力匹配的额外推理基线、基线调参预算，或提取默认参数由哪个划分选定。它披露了 API 访问、GPT/Gemini 中等推理强度，以及本地 Qwen 硬件，却没有给出轨迹收集、技能提取、标准发现的 token、金额或墙钟时间；建库成本仍未量化。
- **泄漏边界。** 提取使用经验划分轨迹，且提示词要求删除任务特定细节；论文未报告对评测任务重叠、近重复或任务亲缘泄漏的实测审计。相关任务仍可能共享流程细节；这是证据边界，并不证明发生了污染。标准开发使用下游效用，与技能直接包含测试任务是两个问题。

## 增益缺失或较小之处

- **技能变好，不保证比无技能更好。** 表 11 的 ALFWorld Qwen3.5-35B 为 **57.21 无技能 → 53.73 原始技能 → 54.11 效用指导技能**；SpreadsheetBench 中标为 Gemini 的行为 **37.50 → 33.17 → 36.75**。两者的效用指导技能仍低于各自无技能对照。我们保留表 11 的 Gemini 标签；它与表 1 的具体对应关系尚未解决（见 SOURCE.md）。
- **效用指导并非每项比较都最强。** SWE-bench 的 Gemini 行中，合理性指导为 **70.96**，高于效用指导的 **70.58**。“全部九格改善”指相对 Original，不是超过每个竞争条件。
- **小幅或负的均值仍存在。** 表 1 中，SWE-bench Qwen3.5-9B TE 仅 **+0.37**，SEAL-0 Gemini-3.1-Pro TE 为 **−1.04**。没有逐格不确定性，不能把很小的正均值视为已确立的显著胜出。
- **替代 harness 的结果混合。** 附录 F 使用 Claude Code 和 Codex 评测 SpreadsheetBench，整体为 **+0.4 个百分点**。TE 分别为 Claude Code Opus 4.6 **−0.5**、Sonnet 4.6 **+2.3**、Codex GPT-5.4 **+0.7**、Codex GPT-5.4-mini **−1.0**。这是范围有限的 harness 检验，不是生产技能库普遍有效的保证。

## 我们的解读（Our read）

沿用榜单：**65 分 · ★★ · retained**。论文报告了同领域留出评测、表 1 的三次运行均值、格式/经验对照、固定技能跨模型迁移、替代 harness，以及提取指导的比较。没有报告主结果逐格不确定性、成本匹配的基线增益、建库成本、重叠审计，或效用筛选标准的独立验证。表 11 没有单独说明运行/种子聚合方式或提取器身份。附录 C 确实量化了轮次噪声，因此不能说全文没有任何方差分析。

实用结论比“技能有效”更窄：**效用取决于经验来源、提取器与消费者；具体补救措施有帮助，但采纳标准仍应是下游行为，而非文字看起来合理。** 即使元技能改进了提取结果，目标智能体仍可能不如不用技能。
