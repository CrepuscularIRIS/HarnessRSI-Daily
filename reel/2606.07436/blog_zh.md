# Skill-3D：留下场景感知的工具流程，而不只是多调用工具

*Reel 解读：[arXiv 2606.07436v2](https://arxiv.org/abs/2606.07436v2)。完整标题：**Skill-3D: Evolving Scene-Aware Skills for Agentic 3D Spatial Reasoning**。作者依 PDF 顺序为 Haoyuan Li、Zhengdong Hu、Jun Wang、Hehe Fan、Yi Yang。HarnessRSI Daily 评分 **63**，档位 ★★。代码：[skill-3d/Skill-3D](https://github.com/skill-3d/Skill-3D)。*

## 系统改变了自己的什么

Skill-3D 保留视觉问答轨迹的 **Scene Memory**，以及**场景感知技能库**。一条技能是可复用的操作指导：何时适用、需要什么证据、工具调用的顺序与参数，以及如何从证据得到答案。失败转化为教训或后备规则。这是程序性指导，不是学到的运动技能或模拟器策略。

固定的静态种子技能涉及计数、度量距离、相对深度、视角选择、检测与深度融合、检测与分割融合、朝向和重建。动态技能则从经验中提炼。工具包括 Pi3、GroundingDINO、SAM3、Depth Anything 3、Orient Anything v2 和 SwinIR。闭源实验改变外围技能框架；Qwen 实验还通过 SFT 与 GRPO 更新模型权重，因此其收益不能单独归因于技能库演化。

## 迭代回路与保留/拒绝规则

1. 从问题与视觉输入识别场景和任务，检索候选技能，再由策略选出紧凑子集。
2. 执行工具流程，把推理、工具输出、答案及结果记入 Scene Memory。
3. 从成功轨迹提炼新技能；只有增加有用覆盖、更强证据或更低成本流程时才合并到已有技能。重复成功只更新统计。
4. 有证据支持的失败附为教训；失败支持可靠修正时，给动态技能增加后备规则。静态技能下反复发生的失败可产生新动态技能。
5. Skill Manager 只接受有证据支持、且与此前成功案例一致的更新，否则拒绝。图 2 将其画为 MLLM 判断。论文未给数值接受阈值、详细的成功标签判定流程，或独立重跑的回归测试门控；不能写成“按模拟器成功率筛选”。

GPT-5.4 是技能提炼及 SFT 数据生成的教师，仅使用训练样本。各基准训练集汇入同一套共享记忆和技能库，**评测及后训练期间均冻结技能库**。推理时，语义、上下文及证据需求检索还考虑成功历史、教训和成本；策略再决定使用哪些技能。

## 决定收益是否可信的对照实验

- **技能库消融（表 3，GPT-5.4）。** 表中展示的是 VSI 的计数、绝对距离、物体大小、房间大小，不是全部 VSI 类别。论文报告的 Avg.：完整方法 69.9，去失败教训 68.1，去动态技能 67.8，去静态技能 65.6，去 MLLM 技能选择 65.5，去检索 64.1。在表 3 报告的消融中，静态先验及检索/选择的效应大于单独动态技能。没有逐行方差或运行次数。完整方法的 Avg. 与表 1 全部八个 VSI 类别的均值一致，而非这里只展示的四类，但表 3 未明确界定该聚合范围，详见 SOURCE.md；此处保留论文 Avg.，不擅自替换。**无动态技能的 VSI Avg. 在表 3 为 67.8，在表 B.2 却为 63.4；两者的评测/配置关系未获解释。我们只在各表内部比较，不将其当作可互换的动态技能贡献估计。**
- **实际做了跨基准迁移（表 B.2）。** 不是只有混合训练的头条结果：动态技能来自一个源基准，**静态技能和 GPT-5.4 保持相同**。VSI 来源动态技能让目标 MMSI-PR 从无动态技能的 52.6 升到 57.8，CV-3D Avg. 从 92.2 升到 93.7。MMSI 来源技能在 VSI Avg. 得到 67.3，无动态技能为 63.4。另一些迁移幅度很小：BLINK 来源技能在 VSI 为 63.9 对 63.4；CV-3D 来源技能在 BLINK 为 77.5 对 77.2。混合技能库在 MMSI-PR 得到 60.4。这些均值没有方差/置信区间；静态先验共享，并非重置为空库。
- **冻结与继续更新（图 5）。** 在 Qwen3-VL-8B 上，冻结技能并采用 SFT 冷启动的 GRPO 训练奖励曲线最高且最稳定；在线更新技能或跳过 SFT 更差。阴影仅称为“training variance”，未说明种子数及误差带定义，不能作为表 1–3 多种子不确定性的证据。
- **推理效率不等于演化成本（表 B.1，GPT-5.4，VSI）。** Think3D 每题平均 1.8 次调用、35.1 秒；Skill-3D **2.6 次调用、20.8 秒**，检索开销 0.5 秒。直接工具调用更快，为 13.2 秒。Skill-3D 调用次数更多而非更少，只是减少对昂贵重建的依赖。有效工具使用率从直接工具的 39.2% 升到 78.7%，定义为返回可用证据、且后续确实使用了证据的调用占比。这些数字也见于表格与正文，不只是图标签。时间均值没有离散度或明确重复次数。
- **基线获得了什么、预算是否相同。** w/o Tools 没有工具；w/ Tools 直接调用工具；Think3D 是基于重建的智能体对照。论文未报告分别给这些基线提供 Skill-3D 的静态/动态库，也未给出匹配教师、提炼与交互预算的实验。Think3D-4B/8B 和 Skill-3D-4B/8B 的后训练预算是否相同也未确立。因此对照支持整个方案，而不是等预算下技能学习算法的比较。

## 收益较小之处，以及尚未核实的边界

收益并非仅出现在一个展示子任务，但幅度强烈依赖比较对象。Gemini-3-Flash 的 VSI 绝对距离相对无工具从 9.2 到 56.1，出现顺序从 31.3 到 73.4；Think3D 对应已达 52.3、69.3。Gemini-2.5-Pro 的 CV-3D 深度排序只有 94.0 对 Think3D 的 92.7，相对距离为 92.8 对 91.6，幅度小得多。后训练 Qwen3-VL-8B 的 MMSI 同样只有 42.8 对 41.2。没有不确定性估计，无法判断这些小差距是否超出噪声。Skill-3D 也不是推理最快的设置。

**按问题划分，不等于证明场景不重叠。** 论文描述按类别随机取 30% 作训练，其余作不重叠测试。表 C.3 的训练/测试规模：VSI 为 708/1654，MMSI 为 157/345，CV-3D 为 360/840，BLINK 为 40/93。没有报告场景/视频级分离或重叠审计，因此不能排除技能构建与评测共享视觉场景。这是给定视觉观测的室内问答，不是具身导航或模拟器探索；模拟器步数不是该设置中适用且已报告的预算。

**数值设置与调参来源要分开。** 表 C.4 给出了 SFT/GRPO 学习率、批大小、组大小、裁剪及 KL 系数等后训练数值设置；但检索 k、最大工具预算 B、接受阈值的数值未给出。此外，默认值/超参数由哪个划分选择、是否有独立验证集、基线调参预算，均未说明。这不等于“完全没有超参数”。

报告的 500 条 SFT 样本、1k 条 GRPO 样本、一个 epoch、四张 NVIDIA RTX PRO 6000 Blackwell GPU、约 3 小时 SFT 和 28 小时 RL，都是**后训练**，不是技能库构建/演化成本。教师 token、美元、构建 rollout 数和工具调用总量未报告。目标公式将正确性、格式、工具奖励无权相加，实施段落则给正确性/工具/格式权重 0.6/0.2/0.2；论文没有解释两种描述的关系。SOURCE.md 另记录未解决的聚合/报告差异，不猜测原因。

## 我们的解读（Our read）

HarnessRSI 评分 **63**，档位 **★★**，证据等级 **retained**。保留的技能库冻结后在问题级留出数据上评测，且有动态/静态/教训/检索消融。完整附录还报告了源到目标基准迁移，存档判断的 `cross_task: no` 遗漏了这项证据；我们记录这一点，不修改评分及判断文件。论文报告推理和后训练成本，但未报告技能库演化成本、匹配构建预算、场景级泄漏检验或主要分数的不确定性。值得关注的是场景条件化的程序性指导；证据尚不能证明改进器自身变强，也不能证明具身模拟器泛化。
