# RSEA：进化上下文，用验证集把关——但安全保证只到验证集为止

*Reel 解读：[arXiv 2606.28374v1](https://arxiv.org/abs/2606.28374v1)，作者 Michael Nguyen、Quoc Nguyen、Paul Vuong（Monash University Malaysia）。HarnessRSI Daily 评分 **67**，★★。代码：论文宣布发布，但我们的记录未提供代码 URL。*

## 系统改变了自己的什么

RSEA 留存**策略、技能与操作手册**三层自然语言状态：策略提供高层指令，技能提供可复用条件规则，操作手册提供从成功轨迹提炼的流程。状态作为前缀注入标准 ReAct 回路。模型权重与动作/工具接口固定；同一个冻结 LLM 既执行任务，也重写状态。

## 迭代回路与保留/拒绝规则

1. 工作状态与最优状态均从空开始，即原版 ReAct。
2. 在**进化集**运行工作状态，把当前状态、成功与失败轨迹的平衡样本及已验证结果交给重写模型；任何层都可以重写或删除。
3. 在**不相交验证集**评估候选。候选验证分数不低于当前工作状态时，替换工作状态；否则保留当前工作状态。
4. 只有候选**严格超过**历史最优验证分数，才更新冻结最优状态。平局可推进搜索中的工作状态，但不能替换冻结最优状态。
5. 仅把冻结最优状态送入独立测试集。若没有候选严格优于空状态，就返回空状态 ReAct。RSEA+retry 再叠加与重试对照同类的任务内 Reflexion 重试。

这里的验证集相对**重写所用轨迹**是留出的，但其分数反复决定是否采纳候选。被采纳的工作候选在该选择指标上不退步，是规则本身保证的，不是独立泛化证据；独立测试集才提供后者。保证针对验证集，**不是每一次未见测试抽样**，作者在 §10 明确承认这一限制。

ALFWorld 使用与 134 条测试任务分开的 30 条开发任务。工具使用基准的官方开发集被作者认为已饱和，因此从按种子打乱的测试任务池中切出不相交的进化/验证/评估子集。这是基准内部划分，不能当作已验证的分布外迁移。每个基准内部共享骨干与 ReAct 框架，各基准分别进化；论文未报告把某基准的冻结状态迁往另一基准。进化/验证集的确切大小及 episode 重置细节没有印在论文中。

## 论文报告的主要结果

ALFWorld 使用 **Qwen2.5-7B-Instruct、134 条任务、五个种子**。表 2 是均值 ± 95% 置信区间，不是最佳种子结果：

| 方法 | 单次执行成功率（%） | 加重试（%） |
|---|---:|---:|
| ReAct / Reflexion | 64.6 ± 4.3 | 76.4 |
| GEPA | 63.9 ± 5.3 | 75.8 ± 5.4 |
| AWM | 65.4 ± 3.3 | — |
| ACE | 66.9 ± 2.5 | 76.7 ± 4.9 |
| Dynamic Cheatsheet | 70.7 ± 3.4 | — |
| RSEA | 69.3 ± 9.3 | 79.4 ± 7.4 |

论文的配对 McNemar 检验显示，RSEA 优于 ReAct（**p=0.015**）、GEPA（p=0.004）和 AWM（p=0.037），但与 ACE（p=0.20）、Dynamic Cheatsheet（p=0.45）无显著差异。单个均值的置信区间较宽，不等于配对检验失效，但应同时展示。加入重试后均值最高，但相对 Reflexion（p=0.09）、ACE+retry（p=0.13）、GEPA+retry（p=0.052）的比较未确立显著优势。

**排名措辞需要限定。** 正文与图表说明称 RSEA 为最强单次执行方法，但明确标为单次执行的表 2、表 4 中，Dynamic Cheatsheet 为 70.7，RSEA 为 69.3。核对重试变体与其他表格后，仍无法消解这处措辞差异；§6 自己也报告二者差异不显著。我们采用表中排名，把措辞差异保留为未解决问题，不推测原因。

## 决定收益是否可信的对照实验

- **分层消融（表 5）。** 在 54 条 ALFWorld 测试任务 × 三个种子、温度 0.6 下，空状态 ReAct 为 64.2；仅策略 67.3；仅技能 69.8；仅操作手册 69.8；策略+技能 67.9；完整状态 68.5。各层知识重叠，完整组合未超过最强单层。这些是没有逐格方差/置信区间的平均值，协议也不同于表 2。
- **选择消融（表 6）。** 改为在进化集自身选择：**样本内 100.0，测试 66.7**；独立验证选择的测试分数为 **67.3**，空状态为 **63.6**。论文所说的 33 点下降，是样本内到测试的差距，**不是**相对有门控方法下降 33 点。表格未给方差或确切任务/种子数，§8 只统称消融采用多种子解码。这个受控实验中的测试差异较小，不确定性未报告。
- **基线有没有相同机制？** GEPA 已有验证小批次上的 Pareto 选择，ACE 已有非严格验证 keep-best（表 1）。AWM 与 Dynamic Cheatsheet 保留原本无门控的机制。论文未做把 RSEA 严格门控赋予全部基线的实验。因此 Dynamic Cheatsheet 在 WebShop 的崩溃不是同一方法内部、只改门控的孤立对照。
- **预算与调参。** 作者声称每方法 rollout 预算相同、骨干和解码预算共享。这只是部分预算匹配：元调用与注入上下文仍不同。最优状态由验证集选择；超参数/默认值在哪个划分上选定、基线调参预算、各方法确切 rollout 次数、重试上限，完整 PDF（包括附录 B）均未报告。
- **成本（§9）。** 每代有进化 rollout、一次重写与验证 rollout；τ-bench 进化用了 **190 次元调用+选择调用**。推理最多增加几百个前缀 token。没有逐方法的金额/token/墙钟成本表来证明总算力相同。

## 增益缺失或较小之处

收益集中在**较小骨干的 ALFWorld**，尤其是程序性任务族（表 3）：examine **6.7 → 26.7**、pick_two **36.5 → 43.5**、pick_and_place **82.5 → 91.7**。heat **76.5 → 79.1**、cool **81.0 → 83.8** 变化较小；clean 从 **80.0 降至 73.5**，即使加重试得到 **79.4**，仍低于该类别的 ReAct。论文未给任务族数量，无法仅凭 PDF 核验分类加权均值与总均值是否对齐。

其余基准使用 **Qwen3-30B-A3B-Instruct**（表 4）：

| 评估 | ReAct | RSEA | 已报告的最强基线 |
|---|---:|---:|---|
| GAIA，30 条文本任务，准确率 % | 16.7 | 13.3 | ReAct 16.7 |
| τ-bench retail，60 条任务，成功率 % | 41.7 | 40.0 | AWM 51.7 |
| WebShop，100 条任务，平均稠密分数 | 0.429 | 0.437 | AWM 0.460 |

GAIA 仅报告 ReAct 与 RSEA。工具使用结果采用**一个打乱划分的种子**，没有逐格方差/置信区间。作者报告与 ReAct 均无显著差异（p>0.1）；GAIA 差距最多一条任务，同一冻结状态的两次评估会翻转差距方向。WebShop 因所有进化候选都损害验证分数而留存空状态；0.437 与 0.429 是分别报告的评估结果，不是空前缀更好的证据。Dynamic Cheatsheet 的 WebShop 为 0.136、τ-bench 为 36.7：上下文进化可能有害，但仅凭这组比较不能隔离原因。

## 我们的解读（Our read）

HarnessRSI 评分 **67**，档位 ★★，证据等级 **retained**。冻结产物在未参与采纳选择的任务上被测试。论文报告了 ALFWorld 多种子统计、分层与选择消融、部分 rollout 预算匹配和部分优化器成本信息；**没有**证明普遍提升、总算力一致、冻结产物跨基准复用，或优化器本身发生进化。

已有判定因去掉留出选择的消融而把泄漏护栏记为 tested。**我们的解读：**这是过拟合/选择控制，不是全面污染审计。论文描述了不相交划分，但完整 PDF 未报告独立的产物对测试内容污染审计。验证门控是有价值的工程设计；单调的选择分数不应被表述为保证测试安全。
