# MGM：让编码智能体用更好的证据改写自己——最大收益来自 Polyglot

*Reel 解读：[arXiv 2608.07645v1](https://arxiv.org/abs/2608.07645v1)。PDF 完整标题为 **Mendel Gödel Machine: Recursive Self-Improving Coding Agents via Comparative Evolution**，作者依次为 Changzhi Liu、Yilun Liu、Sikuan Yan、Volker Tresp、Yunpu Ma。HarnessRSI Daily 评分 **65**，★★。代码：[RealLcz/MGM](https://github.com/RealLcz/MGM)。*

## 系统改变了自己的什么

MGM 修改并继承编码智能体的**可执行脚手架**，不更新底层模型权重。贡献在于改变每次修改所依据的证据：不再孤立诊断一次失败，而是复用智能体变体档案中已有的轨迹。目标智能体自己改写自己的源代码；跨谱系杂交并不是把另一智能体的文件直接拼接进来。

附录 H.1 展示了 Polyglot 谱系实际积累的改动：先读测试与桩文件，再提取结构化 API 契约、按契约实现，最后增加最多五次尝试的测试—修复循环。改变的包括可执行提示、控制流和辅助工具。档案搜索策略及算子配置由论文预先规定；论文没有证明智能体自主改写了这些策略或基准评估器。

## 迭代回路与保留/拒绝规则

1. 保存智能体源代码、谱系、执行轨迹和任务成败。沿用 HGM 的节点级汤普森采样选择评估，用汇总后代结果的谱系级采样选择扩展。
2. 根据已有证据选择可用算子：**克隆变异（CM）**读取一条失败轨迹；**反应规范变异（RM）**比较同一智能体在不同任务上的轨迹，至少有一条失败；**跨谱系杂交（CH）**比较不同智能体在同一任务上的表现，该任务不能被双方都解决。
3. CH 中，若参考方成功就修改失败方；若双方失败则修改效用较高的谱系。子代挂到被修改的谱系下。
4. **有效子代即可进入档案。** 算法 1 在任务评估之前通过 `c.is_valid()` 接纳子代，并未规定必须先超过父代分数。之后的任务结果影响采样和最终选择。有效性检查细节、最终 best-belief 选择的精确公式没有完整交代。
5. 使用有限搜索预算：主实验的 HGM/MGM 各 **200 次任务评估、24 次扩展**。最终报告 best-belief 智能体，不是仅评估很少次数就取得最高观测成功率的节点。

展示的谱系确实组合了连续改动，但论文没有确立长期复利增长速率，也没有实际编码实验的饱和曲线。有限预算、隔离容器和有界任务循环限制了这些实验，不等于无界递归自改进的安全保证。

## 论文报告的主要结果

表 1 使用 Qwen3.6-35B-A3B，同一基准内 HGM 与 MGM 从相同初始脚手架出发：

| 评估设置 | 初始 | HGM | MGM |
|---|---:|---:|---:|
| SWE-bench Verified-60 | 68.3% | 73.3% | 78.3% |
| Polyglot-60 | 50.8% | 77.9% | 93.2% |
| 两个基准的平均 | 59.6% | 75.6% | 85.8% |

相对 HGM 的优势在 Polyglot 上更大：**15.3‡ 个百分点**，而 SWE-bench Verified 为 **5.0 个百分点**。这些是进化任务子集上的结果，不是独立留出任务成绩。实际实验表格给出点估计，没有说明每个单元格的进化运行次数，也没有标准差或置信区间。表中的平均是基准或模型间平均，不是已证实的随机种子均值。

进化结束后，冻结的 Qwen 脚手架在完整 Polyglot 上解决 **210/225 题（93.3%）**（附录 E.1）。完整基准包含进化子集，不能称为完全留出。冻结脚手架并把底层模型换成 DeepSeek-V4-Pro 后，完整 Polyglot 达到 **96.89%**（§5.2）；这是模型迁移，不是进化更新了模型权重。执行设置也改变了：Qwen 开启 thinking，DeepSeek 使用 non-thinking，并采用不同采样配置（附录 C.1，第24页）。论文没有证明跨模型推理预算匹配。

## 决定收益是否可信的对照实验

- **预算匹配的 HGM。** HGM 获得相同祖先、模型、任务子集、评估次数和扩展次数。它已有档案及自适应节点/谱系采样，但只有 CM，没有 MGM 的比较算子。DGM 出现在替代模型模拟中，不在主实际编码比较中。初始脚手架不做进化。除算子消融外，未报告单独给 HGM 增加比较证据的对照，也未用仅改变失败任务池的对照隔离这些因素。
- **算子消融（表 4，仅 Polyglot-60）。** 完整 MGM **93.2%**，去 RM **79.7‡%**，去 CH **74.6‡%**；均从 **50.8%** 出发，200 次评估、两个工作进程。耗时分别 **40.14、43.01‡、39.95‡ 小时**。它们支持这两个算子在该设置中的作用，但没有随机种子不确定性。
- **冻结的跨基准迁移（表 2）。** 将 Polyglot 进化的脚手架直接评估、不再自改进：初始/HGM/MGM 在 SWE-bench Pro 为 **16.7 / 13.3 / 26.7%**，Multilingual 为 **41.7 / 43.3 / 55.0%**。跨基准平均 **29.2 / 28.3 / 40.9%**，无方差或置信区间。附录 D 称通过 ChatGPT 分别随机选取每个目标基准的 60 个代表性任务，并要求语言覆盖；不是完整目标基准。
- **冻结的跨模型迁移（表 3）。** 在 SWE-bench Verified-60 上保留 Qwen 进化的脚手架，仅替换模型：DeepSeek-V4-Flash 的初始/HGM/MGM 为 **50.0 / 60.0 / 66.7%**，DeepSeek-V4-Pro 为 **45.0 / 70.0 / 75.0%**。两个目标模型平均 **47.5 / 65.0 / 70.8%**，不是种子平均。HGM 和 MGM 都能迁移；这里变的是模型，不是评估任务。Qwen 开启 thinking，DeepSeek 使用 non-thinking，采样配置也不同（附录 C.1）；论文没有证明跨模型推理预算匹配。这一限定不否定各目标模型内部的初始/HGM/MGM 比较。
- **默认值与调参。** 表 6 给出 CM/RM/CH 权重 **0.10 / 0.45 / 0.45**，RM 最低任务数为二，失败池权重 **1.0**。按照我们对公式 17 的阅读，最后一个设置没有相对提高失败任务的采样权重，尽管通用方法允许这样做。论文未说明在哪个划分上选定这些默认值，也没有报告 HGM 调参预算。
- **自改进算力成本。** 表 1 报告八张 H100 上 HGM/MGM 的墙钟耗时：SWE-bench **93.02 / 96.11 小时**，Polyglot **44.20 / 40.14 小时**。MGM 并非两处都更快。图 6 及对应正文称算子 token 开销相近，但没有数字化的总 token 或美元费用账单。操作次数相同不等于精确 token 匹配；完整基准模型迁移结果也没有把此前供体进化成本另列为端到端总成本。
- **模拟是有条件的诊断。** 100 个种子、95% 置信区间属于加性适应度模拟，不属于表 1–4 或 7。模拟给比较算子设定修复质量优势；无优势比值 **1.0** 时，MGM 退化为 HGM 式表现。oracle 是理想最优界，不是编码系统竞争者。证明依赖有信息量的比较、稀疏因果缺陷和能利用证据的编辑器。

## 增益缺失或较小之处

- **更换进化模型（表 7）：** Qwen3-Coder-Next-80B-A3B 在 Verified-60 从 **33.3%** 出发，HGM 达 **40.0%**、MGM 达 **41.7%**。**1.7‡ 个百分点**的差距没有不确定性估计，不能称为统计可靠。主结果的优势并不均匀覆盖不同底层模型。
- **语言覆盖不等于逐语言增益对照。** 完整 Polyglot 的解题数为 C++ **25/26**、Go **36/39**、Java **43/47**、JavaScript **46/49**、Python **33/34**、Rust **27/30**。较高绝对成绩覆盖多种语言，但论文没有 HGM 逐语言解题数，无法据此定位相对增益。
- **证据稀疏时：** 作者指出，轨迹少、任务重叠不足时，MGM 可能近似单轨迹方法。
- **未解决的正文/表格差异：** 附录 F.2 对 Qwen3.6 MGM 提及 **61.7%**，但表 1 和表 7 的同设置为 **78.3%**。我们检查了其他模型、迁移和消融行，没有找到能解释该引用的对应结果。采用表格数值，不推测原因。

## 我们的解读（Our read）

HarnessRSI 评分 **65**，档位 ★★，证据等级 **retained**（最新判定 b18）。有用证据包括操作次数匹配的 HGM 比较、算子消融、冻结跨基准/跨模型迁移，以及较高的进化成本报告。这支持留存脚手架的改进，不等于证明搜索策略本身被自主改进。

必须限定泄漏保护范围：论文称进化期间不能访问**私有测试用例或测试结果**，但档案必然使用进化任务的结果，进化代码还明确读取、执行可访问的仓库测试。主 60 题成绩不是另一份留出集，完整 Polyglot 包含该子集；跨基准迁移是更干净的未见任务检验。论文承认公开基准可能与预训练重叠，没有报告专门的污染审计。实际实验的运行/种子方差、默认值选择划分、基线调参预算和长期稳定性仍不明确。

**与 Red Queen Gödel Machine 的关系：** 这份 PDF 没有引用或直接比较 arXiv 2606.26294。明确继承的搜索机制及主要实际编码对照来自 HGM，即 **Huxley Gödel Machine**。我们不引入 Red Queen 论文的机制或结论。
