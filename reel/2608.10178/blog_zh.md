# 同一进化配方，多种 harness：可迁移的是行为纪律，不是原生性能上限

*Reel 解读：**One Recipe, Many Harnesses: What Self-Evolution Encodes Across Languages and Models**（一个配方，多种 Harness：自进化在不同语言与模型间编码了什么）。作者依次为 Siqi Yang、Qianlan Yang、Yu-Xiong Wang、Saurabh Pujar、Martin Hirzel。阅读版本：[arXiv 2608.10178v1](https://arxiv.org/abs/2608.10178v1)。HarnessRSI Daily 评分 **64**，档位 ★★。本篇 Reel 未提供经核实的代码链接。*

## 系统改变了自己的什么

TRIAGE 固定模型权重，编辑其外部 **harness**：提示词模板、工作流钩子、经验记忆和 shell 工具。论文在 Multi-SWE-Bench 的八种编程语言和三个模型上固定同一进化配方。**共享的是配方；每个语言/模型单元的具体 harness 都重新推导。** 不是一份成品通吃所有设置。

每个单元都从相同的最小 ReAct 种子开始：短提示词、一个 shell 工具、空钩子与空记忆。主实验中，任务策略、轨迹分析器和进化智能体使用同一个底层模型。分析器读取失败轨迹、提交补丁、测试输出、评分器各阶段记录和预算轨迹；类型化诊断建议修改哪个槽位，进化智能体写出合约，说明修改意图以及预计修复、破坏哪些实例。记忆最多 12 条，每条 400 字符，含实例特定 token 的条目被拒绝。产物主要是行为纪律，而非新发明的工具。

## 迭代回路与保留/拒绝规则

- 编辑先过冒烟验证；格式或执行不合格就保留旧内容。每轮最多修改两个组件。
- 在**进化集**重跑，验证整个检查点及其合约预测。选择得分为解题率减去 **2.0** 倍的“此前已解、现在丢失”的实例比例。
- 回滚不是即时发生：附录 A.4 容忍 **0.12** 的下降，连续两轮不改善或出现 **0.25** 的灾难性下降才回滚。
- 三轮后，提交进化集上选出的最佳检查点；没有检查点达到种子表现就回退种子。**种子保底仅约束选择数据，不保证测试集不退步。** 验证钩子只是鼓励测试，不阻止提交。

C++/Haiku 示例的进化集分数为 **10.0 → 62.5 → 72.5 → 72.5**，最终提交第二轮检查点。合约获判 confirmed 也不意味着每条预测实现：附录 A.7 记载一个具名修复兑现、四个未兑现。论文还有一处未解决的路由描述差异：A.2 称故意不路由 `wrong_fix`，表 2 却把它列入验证/边界纪律路由。我们不推测实际执行的是哪一种。

## 论文报告的主要结果

**论文陈述的协议**是每种语言随机抽取 **20** 条进化实例和与之不相交的 **50** 条测试实例。但附录 I.1 与表 9 的 rollout 总数无法与所述完整网格及重复次数对上；实际逐单元评测覆盖范围无法从 PDF 核实。指标 **mean_solve@3** 是每条实例三次独立 rollout 的平均解题率，不是三次中至少成功一次的概率。**每个单元只运行一次进化搜索**，不是三个进化随机种子。主要结果来自进化集选中检查点的测试表现。

## 决定收益是否可信的对照实验

**不确定性不等于进化搜索复现。** 表 4 给出种子与 TRIAGE 的重采样不确定性以及配对变化。Haiku Java 为 **2.9 ± 2.0 → 82.9 ± 6.1**，配对增益 **80.0 ± 6.9**。DeepSeek Rust 配对增益 **16.7 ± 9.6**，**z = 1.73**，只越过论文的单星阈值 **1.64**，未达到 **1.96**。GPT-5-mini 无单元达到显著性（**|z| < 1.3**）。表 4 没有给出 mini-SWE-agent 的不确定性。这些不是多次独立搜索得到的置信区间。

**逐个基线说明获得了什么。** 最小种子有任务文本、提交协议与 bash 工具，刻意没有构建/测试/验证/最小 diff 指导。Mini-SWE-agent 使用未经修改的发布配置。两者与 TRIAGE 使用相同容器、评分器和每次 rollout 上限：**80 步、$1.5**。这两个静态基线均未获得 TRIAGE 的进化、编辑合约或检查点门控。除上述配置说明外，论文没有报告基线调参预算。检查点由进化集选择；固定默认值和超参数由哪个划分调出，论文未说明。附录 H 明确承认没有把进化预算用于额外推理 rollout 的总算力匹配基线，没有更强的静态框架，也没有与其他 harness 优化器直接对比。

**机制证据主要来自诊断。** 在恢复的 **256** 条测试实例中，**88%** 的种子轨迹带有检测到的缺陷：**81%** 修改了测试路径，另 **7%** 未修改测试文件却破坏了测试构建（表 6）。这是事后关联，只覆盖可检测缺陷，不覆盖全部可恢复失败。相当部分恢复依赖基准特定协议：修改测试文件会与评分器的隐藏金标准测试补丁冲突。论文承认绝对收益部分体现了对该协议的学习。汇总的增益/缺陷相关系数为 **0.81**，但 GPT-5-mini 内部仅 **0.12**；汇总关系由真正有增益的模型驱动。

**消融范围有限。** 固定 Go 任务策略为 DeepSeek，分别用 GPT-OSS-20B、DeepSeek、Claude Sonnet 4.6 作为元智能体，得分为 **34.2、33.3、35.6**，种子为 **18.5**（表 7）。该单元对照报告三次 rollout 的均值，表内没有方差/置信区间。它支持这里对驱动模型强弱不太敏感，不证明路由或合约分别具有独立因果作用；这些组件、门控与双轴编辑均未单独消融。在另一个重复代码任务族探针中，预装工具为 **9.3**，无工具为 **22.2**，种子均为 **11.1**（表 8，无方差/置信区间）。不能把该选定任务族的结果与主网格 C++/Haiku 的 **87.1** 混为一谈。

**成本包括产生反馈数据的回路。** 附录 I 分别报告元模型计费 **$256**、rollout 计费 **$3,667**。表 9 是类别总账，不是逐个 harness 的预算匹配账单：主网格 **$1,415**、mini-SWE-agent **$357**、迁移 **$1,088**、通用蒸馏 **$615**。rollout 上限相同，不等于实际花费或总优化预算相同。源 harness 的进化与全语言蒸馏不能当作免费的迁移前置工作。**评测账目仍未对齐：**附录 I.1 将 **2,820** 条留出集 rollout 归于整个网格、三个实验臂、k=3 的评测；表 9 重复该数，同时另列 **1,606** 条 mini-SWE-agent rollout。两者均无法与所述完整网格协议对上。我们保留论文报告的分数，但无法从 PDF 核实实际逐单元覆盖范围，不推测原因。

## 究竟迁移了什么，又重新推导了什么

这里有不同实验，不能合并成一个笼统的“迁移”：

1. **配方复用：** 每个语言/模型单元用自己的进化实例和诊断，分别重新进化提示词、钩子、记忆与工具。
2. **完整 harness 移植：** 将源语言 harness **原样**部署到另一语言的测试实例，不做目标适配；执行模型始终为 DeepSeek-V4-Flash。原生对照是在目标语言上另行进化的产物。
3. **通用蒸馏：** 元模型把**所有语言**的进化记忆合成十条通用记忆规则，移除具体构建命令、测试路径与文件布局约定，原样部署同一产物，**仅使用 DeepSeek-V4-Flash 评测**（第 4.5 节）。这不是留一语言测试：记忆池包含目标语言的进化经验。

保留率 **ρ =（迁移得分 − 种子得分）/（原生得分 − 种子得分）**，表示保留原生*增益*的比例，不是解题率。第 4.6 节报告 **18/20** 对迁移为正、**14/20** 低于原生，平均保留率 **0.63**，没有逐对方差/置信区间。源/目标组合很重要：C++→TypeScript **1.50**、Java→TypeScript **1.40**、Go→TypeScript **1.30**，都超过原生点估计；JavaScript→C++ 为 **1.32**，但 JavaScript→TypeScript 为 **−2.30**，甚至低于种子。Go→JavaScript 也为负（**−0.09‡**，图 7 标签）。所以原生只是参照，并非不可突破的上限。

通用记忆方面，**仅在 DeepSeek-V4-Flash 上**，第 4.5 节报告 JavaScript **1.13**、Go **1.08**，称与原生在统计上不可区分；而 Java **0.68**、C++ **0.65**、TypeScript **0.48**，仅保留部分原生增益。该处没有给出相应数值区间，后几种目标上原生进化更好。Haiku 和 DeepSeek 的概念重叠为 **0.55、0.57**，生态 token 重叠为 **0.12、0.14**。内容分析只纳入它们有正增益的非 Python 单元；自动 LLM 标签和词法标记限制了解释范围。论文笼统称每个 harness 的生态特定内容为 **20–40%**，但表 5 的 Haiku JavaScript 为 **18%**，这一例外尚未解释。

**迁移泄漏与预算。** 附录 B.1 称测试实例不参与编辑提议、评分或选择，各变体复用同一个目标测试集；记忆 token 过滤也是一道防护。但论文未报告跨语言的“源进化集/目标测试集”实例或仓库重叠审计，因此上述保证不足以证明跨语言数据隔离；我们不声称发生了泄漏。各原生搜索采用相同轮数与 rollout 上限，但未报告逐 harness 实际成本匹配，也没有总预算匹配的移植/蒸馏比较。

## 增益缺失或较小之处

- **GPT-5-mini：** 对种子最大正变化 C **28.3 → 36.7**，按表 4 阈值仍不显著（**8.3 ± 6.8**，**z = 1.22**）；mini-SWE-agent 在此达到 **46.7**。其他任务有零变化或负变化。该无增益区域是事后识别的。
- **Python：** Haiku **75.0 → 73.2**、GPT-5-mini **67.9 → 67.9**、DeepSeek **73.2 → 66.1**。不能全概括成严格持平：表 4 给 DeepSeek 配对变化 **−7.1 ± 4.2**、**z = −1.69**，按论文阈值属于单星负向，尽管正文把 Python 归为无增益区域。
- **新操作知识：** 人工植入事实的探针未学会特定补救办法：对照 **78.3 → 76.1**、额外显式提供错误文字条件 **76.1 → 71.7**，作者称两者均在噪声范围内。这支持更窄的结论：识别并安装已有纪律，而非已经证明发现新的环境特定事实。
- **范围：** 仓库修复、小规模语言内随机划分、三轮进化、每单元一次搜索。长时程行为和进化随机种子的稳定性尚未测试。

## 我们的解读（Our read）

HarnessRSI 评分 **64**，档位 ★★，证据等级 **retained**。保留的 harness 在不相交实例上测试，并测量了可迁移性，但诊断路由、合约与选择机制没有被分别隔离。**报告了：** 留出集评测、跨语言复用/蒸馏、rollout/重采样不确定性、驱动模型消融、负结果探针与优化器/rollout 成本。**未报告：** 独立进化种子方差、总算力匹配基线、逐对迁移不确定性、独立的路由/合约/门控消融，以及跨语言泄漏审计。

既有 b12 判断把优化器成本留为 unclear，但完整附录确有报告；其中方差的“no”应限定为没有重复进化搜索，不能理解为完全没有不确定性证据。我们不修改分数或判断文件，在 SOURCE.md 中记录这些限定。
