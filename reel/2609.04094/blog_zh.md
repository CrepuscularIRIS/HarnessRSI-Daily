# DRACO：让模型评委写评分细则，再把学习信号分配到智能体的具体步骤

*Reel 解读：[DRACO: Fine-Grained Credit Assignment with Dynamic Rubrics for Long-Horizon Agent Training](https://arxiv.org/abs/2609.04094v1)。作者依次为 Shubham Gandhi、Saurabh Goyal、Kiran Kate、Yara Rizk。HarnessRSI Daily 评分 **66**，档位 **★★**。代码：[IBM/draco](https://github.com/IBM/draco)。*

## 系统改变了自己的什么

DRACO 通过 **LoRA 训练改变策略权重**，同时根据智能体的执行轨迹生成新的评分细则。它没有保留一份改写后的提示词、工具或 harness 程序。这与本仓库“非权重 harness-RSI”的范围存在区别：看板记录的证据等级是 `retained`，但这里留存的学习产物是权重适配器，不是 harness 补丁。

它对评估器设计仍有借鉴意义：没有训练期任务成功检查器时，模型评委能否提供比“同一个奖励复制到所有步骤”更有效的信号？

## 迭代回路与保留/拒绝规则

1. 每个训练任务采样六条轨迹。冻结的 GPT-5.4 评委先根据任务指令生成细则，再从每条轨迹的实际失误补充细则，合并去重后形成该组共享的 rubric。
2. 对完整轨迹逐项判定通过、失败或不适用。**只保留组内至少有一条轨迹失败的细则**；这是细则筛选，不是真实成功信号把关。奖励为适用且保留的细则中 `(通过数 − 失败数) / (通过数 + 失败数)`。
3. 独立的归因阶段让评委指出造成每项判定的步骤，可以确认或改判前一阶段的结论。步骤质量是引用它的细则中的通过比例；未被引用的步骤继承被引用步骤的平均质量。
4. GRPO 在组内归一化奖励。组相对优势为正时，集中强化评委认为好的步骤；为负时，集中抑制评委认为差的步骤。信用用于加权**策略梯度更新**，不是选出最优轨迹或保留某个补丁。

闭式重分配守恒的是被分配 token 上优势的标量总和，**不是梯度向量**。规则考虑步骤长度，排除间隙 token；没有可用归因或归一化项退化时回退到均匀优势。实际任务失败的轨迹也可能是组内相对赢家。权重更新没有真实成功验证器的接受/拒绝门槛；报告检查点采用预定的训练末期安排，不按测试最优挑选。

## 论文报告的主要结果

训练只用 AppWorld 的 90 个训练任务。评测覆盖 test_normal（TN，168 个任务）、test_challenge（TC，417 个任务，包含未见应用与组合模式），以及零样本迁移的 τ-bench Banking（97 个任务）。TGC 为任务目标完成率，SGC 为整个场景完成率，SR 为成功率。下表均为 p1 平均成功率，单位为百分比（表 2）。

| Qwen3.6-27B | Base | 结果奖励 GRPO | DRACO |
|---|---:|---:|---:|
| AppWorld TN TGC | 69.4 | 80.0 | 85.3 |
| AppWorld TN SGC | 41.1 | 59.3 | 70.6 |
| AppWorld TC TGC | 49.7 | 59.9 | 61.5 |
| AppWorld TC SGC | 30.2 | 38.3 | 40.7 |
| τ-bench Banking SR | 15.8 | 17.6 | 20.4 |

论文报告 TN 上比 Base 高 **15.9 个 TGC 点**，比结果奖励 GRPO 高 **5.3 点**。摘要另一个“迁移提升 **5.3 点**”指的是**自评委**版本的 21.1 对 Base 15.8，不是前沿评委版本的 20.4。它们对应不同变体，不是数字矛盾。

这些数字既不是最佳检查点，也不是独立训练种子的均值。Qwen3.6-27B 训练 100 步，头条取第 90、95、100 步检查点的均值，每个检查点评测三次。Qwen2.5-32B-Instruct 训练 75 步，取第 65、70、75 步。表 4 中训练行的标准差是**跨检查点**的；Base 是一个检查点三次推理的标准差。论文明确未刻画训练运行的变异性。行级 Average 没有标准差或置信区间。

## 决定收益是否可信的对照实验

- **细则/信用的交叉消融。** TN 上，静态细则/无信用为 TGC/SGC **81.1/59.9**；静态细则/有信用为 **81.9/60.7**；动态细则/无信用为 **82.1/64.9**；完整 DRACO 为 **85.3/70.6**。动态细则上增加信用对应论文报告的 **+3.2/+5.7**。静态细则不是空白基线：它由训练任务上的 720 条未训练策略轨迹和 GPT-5.4 提议构建。静态/有信用组获得可比的评委步骤归因；无信用组和普通结果奖励 GRPO 没有。论文未报告“结果奖励加 DRACO 信用”的对照。另一模型的已发表 SALT 是结果可见的步骤信用参照，不是匹配的结果盲竞争者。
- **随机奖励训练也能改善 Base。** 第 4.3 节报告 TN TGC/SGC 为 **74.0/50.0**，高于 Base 的 **69.4/41.1**，但低于 DRACO 的 **85.3/70.6**。因此，没有所提信用信号时也会出现部分提升。这个对照既不验证步骤因果归因，也不能替代“结果奖励加步骤信用”的对照。
- **RL 日程相同，总成本不同。** 各组共享预先确定的超参数：16 个提示、每个六条轨迹、每次运行八张 H100、rank-16 LoRA。论文没有说明这些默认值在哪个 split 上选定，也未报告超参数搜索或基线调参预算。优化步数相同，不等于评委花费相同。作者避免按测试表现选检查点，但未报告污染审计。
- **方差能说明什么。** TN TGC 为 **85.3 ± 1.5**，结果奖励为 **80.0 ± 1.9**；TC 为 **61.5 ± 1.0** 对 **59.9 ± 1.2**。这些检查点标准差不是多种子稳健性，也不是差值置信区间。p1 汇总 **55.7** 对最佳消融 **53.3** 只是描述性平均，没有汇总不确定性。
- **评委定义目标，而不是提供真值。** 细则和步骤引用由模型根据任务指令与轨迹文本计算，不读取标准答案或训练期单元测试。AppWorld 最终用程序测试评测，是独立于训练奖励的信号。τ-bench 使用状态匹配 SR，同时让 GPT-5.4 充当用户模拟器和评委，因此并非完全独立于前沿评委。我们的解读是：评委偏好可能有利于它训练出的行为；论文没有证明发生了这种偏袒。作者明确将人工验证细则与步骤因果归因留作未来工作。
- **自评委经过测试，不等于得到正确性认证。** 主自评委启用思考，每项通过需要三次评分一致。较弱的单次调用/无思考回放与 GPT-5.4 的判定一致率为 **89.4%**，恒判通过为 **72.0%**。它将前沿评委判失败的细则中的 **30.4%** 判为通过，却只将前沿评委判通过的 **1.3%** 判为失败。这是与前沿评委的一致性，不是人工正确率。回放生成和合并使用归档的前沿评委输入，不是独立、端到端的自评委归因审计。

## 增益缺失或较小之处

- **额外收益更多体现在 TN，不是所有任务统一改善。** TC SGC 完整系统 **40.7**，低于静态/无信用 **42.4**。三次均成功的 p3 指标上，TC TGC **43.9** 低于 **45.6**，Banking SR **8.6** 低于动态/无信用 **9.3**。表 6 中 TN 困难任务 SGC 为 **51.9**，动态/无信用为 **55.0**；中等难度上的强收益没有覆盖所有难度指标。
- **迁移优势偏薄。** 前沿评委版 Banking SR **20.4 ± 1.0**，动态/无信用 **19.7 ± 0.5**，差距与检查点波动相当，没有显著性检验。自评委最高，为 **21.1 ± 1.4**。Qwen2.5-32B-Instruct 的 Banking 仅 **3.4 ± 0.6 → 4.0 ± 1.0**，波动范围重叠，迁移证据弱于 AppWorld 收益。
- **另一模型没有超过结果可见的步骤信用参照。** Qwen2.5 的 TN TGC/SGC 从 **35.7/17.3 → 62.9/42.3**，但已发表 SALT 为 **66.2/47.9**；TC 为 **34.0/19.2**，SALT 为 **36.8/20.9**。SALT 使用真实结果，本实验未匹配其训练/调参预算。
- **推理省钱不等于自动抵消训练成本。** TN 评测成本 **$10.77 → $8.27**，TC **$43.56 → $38.03**。完整评委管线在 100 个训练步上另花 **$1607**，静态/无信用为 **$570**。图 8 的完整 DRACO 中，任务细则生成为 **$63‡**，轨迹细则生成为 **$527‡**，合并为 **$318‡**，步骤归因为 **$308‡**。这些都是评委成本，不含 GPU 总开销。图 8 将 **$316** 明确归给启用思考、三次评分调用的主自评委，与表 2 和表 7 的主行对应。第 4.3 节在提到较弱的单次调用/无思考变体后，附近措辞的指代含糊；论文没有单独标明该较弱变体的成本。静态细则前期构建是否计入也未说明。

## 我们的解读（Our read）

看板记录为 **66**、**★★**、证据等级 **retained**（判断批次 b07）。全文报告了留出评测、跨基准迁移、细则/信用消融、评委成本，以及检查点/推理变异性；**没有**建立训练种子稳健性、人工验证的细则/步骤判定有效性，或评委成本匹配的基线，也未报告实测泄漏审计。留存产物是 LoRA 适配器，这对关注非权重 harness 改动的看板是范围边界。

我们的结论比“细粒度信用解决归因”更窄：动态细则与信用的组合改善了留出 AppWorld 表现，尤其是 TN 场景完成率，但任务成功不能证明被引用步骤的因果归因正确。显式长度归一化公式在一致、非退化判定时给出相同的**步骤总信用**，而不是均匀 token 优势；附录 B.3 的“exactly baseline GRPO”简述需要结合 E.7/E.9 更精确的公式理解。
