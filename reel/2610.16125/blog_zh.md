# 被动模仿（Passive Imitation）：符号控制器逐阶段局部修补，只有经完整任务确认后才主动复用——仅限一个合成领域

*Reel 解读：《Imitation Holds a Key to Evolution: Localized Repair and Verified Skill Acquisition for Adaptive Agents》（[arXiv 2610.16125v1](https://arxiv.org/abs/2610.16125v1)；Kai Hu、Hua Huang；HarnessRSI Daily 评分 68，★★）。代码：[FriendOfYishan/PI](https://github.com/FriendOfYishan/PI)。*

## 系统改变了自己的什么

这不是 LLM 智能体，而是一个确定性的符号控制器（没有神经网络，没有梯度更新），运行在一个合成领域里：一条小型模拟"报表流水线"，三个有序阶段（选取记录、解析版本、金额归一化），每个阶段有 2–3 个不透明的动作（共 18 种完整程序）。十个模拟工具世界各自对工具版本 A、B、C 随机置换动作标识符的真实含义。

被修改的有两处：

1. **当前程序**（单个回合内）：只替换出错阶段的那一个动作。
2. **持久证据表**：以（工具版本、阶段、局部目标）和动作为键，记录成功/失败次数、累计"激励"值，以及完整通过的不同任务编号集合。表中保存任务编号；作者指出它会随习得流增长。

## 信号与保留/拒绝规则

- **信号**：结构化反馈指出被违反的输出路径；公开的数据血缘映射把路径对应到产生它的阶段；请求给出局部目标。论文强调这种反馈很强，且效果识别与目标投影都是预先编程的（预定义的效果词表）。
- **候选**：先取已有正向证据的动作，再取与局部目标同阶段、同效果的源示范片段（优先当前版本），最后是其余所有类型相符的动作。
- **小试验**：把补丁后的程序在两个订单历史构成的子集上运行；只有目标阶段契约通过才暂时保留补丁，判据不是奖励的正负。
- **完整验证**：与独立参考计算比对的整任务审计决定是否接受。
- **存什么**：习得期间，每次小试验都会为被试动作累加成功/失败次数和激励值，无论整任务之后是否被接受；完整通过的任务再为其最终程序中的每个动作加一次成功和一单位激励，并把任务编号加入确认集合。
- **主动复用**：一个动作要进入后续任务的初始程序，需要两个不同的完整通过任务且得分 q ≥ 0.7。评测期间证据表被冻结（用状态哈希检查）。

## 论文报告的主要结果（表 1，K = 3 次小试验，十个世界，每世界每组 60 个任务）

| 条件 | 整轨迹重放 | 完整 PI |
|---|---|---|
| 冷启动留出组合任务，最终成功率 | 6.17% | 100.00%（平均 1.74 次小试验） |
| 96 个原子习得任务之后，首次提交成功率 | 6.17% | 100.00% |
| 未见工具版本 C，最终成功率（跨世界标准差） | 22.67%（12.02） | 70.00%（21.20） |

附带破坏（初始通过的阶段在最终审计时失败）：重放为 12.83%，PI 为 0.00%。600 个冷启动组合任务是十个共用同一任务生成器的世界 × 每世界 60 个任务，并非 600 个独立环境；标准差是跨世界的，不是任务级置信区间。

## 决定收益是否真实的对照

- **试验预算相同**：所有控制器共用同一个解释器、同样的任务、公开信息与同样的 K。整轨迹对照只能重放完整源程序；论文自己称之为组合任务上的"表示劣势"，并说这"不能说明现代基于记忆的智能体会失败"。
- **真正有信息量的对照：组合式修复（compositional repair）**。它保留局部、以目标为导向的试验和两任务确认，只去掉分数阈值与源片段的证据排序。在论文报告的设置中，它的成功率与 PI 相同；试验次数、工作量、附带破坏只在冷启动 K = 3（表 1）中报告，同样与 PI 一致，图 2 中它的曲线与 PI 重叠。论文的结论是这一比较"避免把组合结果唯一地归因于激励分数"（prevents attributing ... uniquely），并称这一持平"合理且很重要"。命题 2 论证：*若*通过的任务能认证唯一正确的动作，则 0.7 阈值不会增加延迟；论文说这"不是普遍等价"，带噪测试可使前提失效。附录代码在其他路径中仍按激励分数给动作排序，所以该对照与 PI 共享部分辅助排序——"有针对性的对照，而非独立设计的竞争系统"。
- **局部化与目标匹配**：去掉局部化，冷启动成功率降到 9.50%，附带破坏 41.83%；去掉效果—目标匹配为 92.50%（1.90 次试验）。
- **小试验**："无小试验"变体同样在冷启动上达到 100.00%，试验 0.00 次，工作量更少（冷启动留出组合上 58.82 对 75.90 行-阶段访问）。
- **保留**：关闭保留（"no retention"）后，冷启动最终成功率仍是 100.00%，但 96 个习得任务之后的首次提交成功率停在 6.17%。在这些熟悉版本的组合任务上，评测平均工作量为：无保留 75.90，有保留 28.98（解释器工作量代理指标下降 61.82%；不含习得、示范与检索成本，论文明确说它不是 token 或成本度量）。论文指出这不是对奖励公式的干净消融。在未见版本 C 上，保留没有带来任何收益：无保留、PI、组合式修复都是 70.00%（标准差 21.20），因为带版本键的记录不授权在 C 上主动复用。
- **无示范枚举**："只做自我试验"（无源示范，其余局部化、验证、学习都保留）冷启动成功率 80.33%，习得后首次成功率 100.00%。
- **留出与方差**：最终任务编号与习得、源示范、探针任务编号互不相交，但所有任务都来自同一个人工设计的生成器。标准差是跨十个世界的，且只在"未见版本 C"一列给出；论文只做描述性比较，不设显著性阈值。穷举完整性检查覆盖 3,600 个任务 × 18 个程序（64,800 次完整/微任务比对）。

## 收益缺失或很小的地方

- **未见工具版本**：PI 的 70.00% 低于自我试验枚举（79.00%）和无目标匹配变体（76.00%），但差距小于跨世界标准差（21.20、9.91、19.57），论文也没有做检验，所以这些差异未经检验、落在标准差之内。K = 1 时 PI 为 21.5%，"无小试验"为 24.0%；K = 1 的数值没有给标准差，同样未经检验。K = 6 时 PI、组合式修复、自我试验全部达到 100%，且自我试验用的试验更少（2.46 对 2.67）。论文的结论是：由源示范带来的候选排序"并非处处有用"，会占用稀缺的试验次数。
- **对版本 C 的探索性适应**：在 24 个单独生成的 C 任务之后，PI 的首次提交成功率从 6.17% 升到 54.33%（6 个任务后）、92.33%（12 个）、100%（24 个），最终成功率从 70.0% 升到 100%。该后续实验在看到主实验结果之后才设计，论文标注为探索性。24 个任务的流把 12 种多目标组合各出现两次，最终的未见 C 任务也是组合任务，因此请求类型看起来大幅重叠（我们对 6.2 与 7.4 节的解读）；评测反复使用同一批冻结的 C 任务（论文图 2 的说明称之为"在已学会版本内的保留"，而非未见版本迁移）。组合式对照的曲线相同；论文说该实验既不证明零样本迁移，也不证明数值激励优于更简单的已验证复用。
- **持平**：习得之后，PI、组合式对照、自我试验、无局部化、无目标匹配都达到 100.00% 首次成功率，终态无法区分它们；差别只在冷启动修复与未见版本上。
- **作者自述的范围**：单一合成领域（十个共用同一生成器的工具世界）、18 种程序、预定义的阶段边界；提供了角色绑定、类型化血缘与阶段断言；微任务夹具按构造就具有辨识力；阈值与成本系数未跨环境验证。研究没有测量语言模型 token，也没有限制持久存储，没有可比较的延迟数据（附录只给出未做性能剖析的整次运行时间，约 21.93 s 和 3.49 s，论文声明不用于比较）。论文引用了 Reflexion、ExpeL、Agent Workflow Memory 等，但没有与之比较。其结论原话是"a limited correction-and-retention mechanism rather than a unique incentive advantage or general intelligence"（有限的纠错与保留机制，而非独特的激励优势或通用智能）。

## 我们的判断

HarnessRSI 评分 **68**，档位 ★★，证据等级 **retained**：被保留的证据表在与构建它所用任务不相交的任务上改进了后续首次提交，且有无保留消融佐证。论文报告了：留出评测、保留消融、同一试验预算下的局部化/目标/试验消融、十个世界及"未见版本"列的跨世界标准差、带状态哈希的穷举完整性检查、已发布代码。论文没有报告：LLM 智能体或自然语言设置、含习得成本的 token/成本、与外部智能体方法的比较、以及自身对照之外的改进机制比较。最强的对照与该方法持平，作者自己也这样陈述。
