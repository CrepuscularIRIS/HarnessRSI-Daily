自洽权分给谁：
把 govern / propose / judge 拆给三个主人

EvoTrias 认为程序自进化系统的瓶颈不在算力也不在模型，而在"三种决策的自治权被错配"。控制器系抓 govern 弃 propose，agent 系让一个 agent 全抓；两系都不保护 judge。分权之后：同预算更强、token 省 64%、评估器私有让分数更忠实于迁移。

PLANE 1 · 跨轮之事

Structured Governance 治理层

沉淀已核实的结论为证据，驱动选择策略与持久经验；决定每个新任务拿到什么上下文。
owner：治理引擎（非 coding agent）
对照：agent 系里单次尝试的教训直进共享记忆、无人把关 → 搜索过早收窄；治理移出 agent 轨迹，算力集中到构造候选。

PLANE 2 · 任务之内

Open Proposal 提案层

通用 coding agent（Claude Code / OpenCode）在任务内自由调用工具、自主推理直到产出 artifact。
owner：任意通用 coding agent（可插拔）
对照：控制器系里 propose 只是单次 LLM 调用，只见控制器拼好的上下文，做不动大仓库。

PLANE 3 · 分数之门

Protected Judgment 裁判层

评估器源码与官方结果私有，只返回归一化 outcome：validity / fitness / metrics。
owner：运行时钩子层（工具调用前拦截评估器读取）
对照：两系都把 grader 源码链进 agent 工作区——搜索可以"学怎么被评分"而不是"学任务"。

暴露时程序学到了什么

终程序按五固定信号族路由到分开调度的滤波器、强制 last-sample lag=0、按评估器对齐方式打分——注释自述"调过 grader 的固定种子"。Original 0.809 → OOD 0.688。

保护时程序学到了什么

单一信号无关管线：Haar-MAD 噪声估计 + 自相关 Matérn 长度尺度。Original 0.719 → OOD 0.730——看不见用例，就学真算法。

边界条件：Circle Packing（评分对象就是那一个指定排布）暴露效应 <1%——可见性伤害发生在"要在不可见实例上泛化"的任务族。暴露平均抬 Original +0.093，OOD 只剩 +0.009。

这张图没有证明什么

对 judge 边界没有独立渗透测试（无红队专门攻击钩子层）；Math/ADRS 领先是同 wall-clock 而非同 token 口径；三平面归属与消融（去 judge / 去 governance 各自掉分）见原文附录；SOTA 对照含 OpenEvolve / EvoX / AdaEvolve / CORAL-1/4。全部数值为作者报告，本项目未复现。
