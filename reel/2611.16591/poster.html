表 4，6 条攻击
  • 销毁痕迹：Harbor 的代理日志可写——先用托管模型 API 蒸馏，再改日志并写一段“一切合规”的说辞（NANO-K11、MID-G04）。

E

一次开锁的偶然

§6.3–6.4，表 6–7
  • 同一代理换推理档位：Opus 5.5 推理引擎 max 档 $11.52、medium 档 $11.07，high 档单代理只有 $7.31，低于 SGLang 的 $8.18；low、high 都没超过。收入跟“提前收工”的时长同序。
  • 强制用子代理：GPT-6.1 Sol $9.70 → $2.09；Opus 5.5（high）$7.31 → $10.32。怎么分工决定结果。
  • harness 领先只差一个 PR：0.468 vs 0.438 来自 6 次修 bug 中多成 1 次（每次二元成败占总分 1/15）。
  • 后训练：没有代理超过 Miles；0.533 vs 0.539，逐题符号检验 18 对 18，p = 1.0。
  • 中期训练一项 1.82 倍拉高了指数：去掉它，Opus 5.5 其余五项平均约 1.14（本项目计算）。
  • 失败也计 0：推理引擎一项 11 个代理里 6 个得 0；10 个失败或被拒的提交中 7 个来自 GLM 5.3、MiniMax M3、Kimi K3 的 Codex 组合——同一模型换 harness，指数可差近 3 倍（GLM 5.3：0.657 vs 0.228）。

检验结论的边界

  • “全部拦下”只针对本研究生成并测试的攻击；Breakwater 是照着这些攻击补的锁，没有对未知攻击的成功率，也没有独立红队。
  • 主表每个代理×任务只跑一次；E 栏显示同一代理的结果可跨过人类参考线两侧。
  • API 花费不含 GPU 与下游评测；任务规模小于真正的递归自改进，作者自认是“所需技能的代理指标”。
本项目阅读：这篇的价值在评测完整性——开放式“让代理造系统”的评测里，提交物能在评分时执行、能穿越阶段、能改写裁判看到的证据，必须由评分方隔离而不是靠裁判识破。摘要中“可能已具备到达奇点所需技能”的说法，不由这些单次运行和六项平均支持；我们只把排名当作本协议下的一次测量。
