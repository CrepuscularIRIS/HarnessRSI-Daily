## Correction（不改 L2 文件；退回 Sol 单篇修订）

- **C1 · 2601.03192（MemRL）**：L2 子卡写“冻结库 holdout 支持”、fact 引用 Table 2 平均 .709/.766/.794 作留出证据。原文 Table 2 标题为“using the best validation results”，而 E.3 中 OS/DB/BCB 只有一次 7:3 划分（seed 42），ALFWorld 迁移集为 valid_seen（已见任务类型的新实例），没有独立于该划分的测试集。报告值可能是在被报告的划分上选出的最佳结果；增益 +2.8pp，且无方差。建议：q4_fit → `partial`、evidence_status → `pending_experiment`（需确认“best validation”的选择对象和是否另有测试划分）；问题档位不变。
- **C2 · 2601.04620（AgentDevel）**：L2 判 q4 `fits`、`confirmed`，核心依据为 Table 3 去门控后 P→F 14.8% 对 3.1%。原文 Table 3 注明 F→P/P→F 均在 D_train 上计算，而门控本身就按 D_train 的 P→F 拒绝候选，这一差异在构造上必然出现，不能说明门控减少了未见数据上的退化；未报告 TestSet 的翻转；去门控的测试分反而更高（35.0 vs 34.2）。另有：门控阈值与“bad release”阈值未给出（“不规定统一阈值”）；TrainSet/TestSet 规模与迭代次数未报告；WebArena 完整版在 Table 1 为 35.5、Table 3 为 34.2，没有说明；Table 1 对照为引用值。建议：q4_fit → `partial`、evidence_status → `pending_experiment`（需 TestSet 级 P→F 和明确的门控规则）；问题本身仍成立。
- **C3 · 2602.15654（Zombie Agents）事实措辞**：L2 fact 写“反思可将约77% ASR降约12%或3–15%”。原文 §4.2 为 Raw History ASR 约 77%，Verbal Reflection 与 Refined Experience **降至**约 12% 与约 3–15%。这是大幅下降而非小幅下降，影响“记忆演化本身是否部分防御”的展示口径。档位与入选不变，建议 Sol 修正 fact 文本。
