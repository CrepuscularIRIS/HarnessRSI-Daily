arXiv: 2611.21688    title: DeltaHarness: Self-Evolving Harnesses for Resource-Adaptive Tool Execution

[abstract]
Tool-using agents rely on execution harnesses to organize and schedule tool operations. The same task and resource description can conceal runtime conditions that reverse the latency ordering of valid execution plans. Resolving this uncertainty requires firsthand execution in the target setting. We introduce DeltaHarness, an execution-guided policy-search method that adapts agent harnesses from cold-start measurements. Its QHI loop uses the observed response to update runtime dispatch, revise physical plans, and select experiments for later proposals. An independent confirmation panel controls policy replacement. With fixed dispatch, a revised materialization policy reduces complete-delivery latency by 30.0% on one video-editing task across three fresh pairs. On held-out tasks, the evolved policies reduce latency by 8.2% relative to the best fixed plan in one seed and by 4.6% relative to the initial proposal in another.

Tool-using language models execute tasks through harnesses that organize tool operations and control their execution ( Lyu et al., 2024 ; Wu et al., 2026 ; Jiang et al., 2026a ) . Resource-aware execution exposes choices in dataflow structure, input access, and scheduling ( Poms et al., 2018 ; Chaudhry et al., 2026 ) . A video composition can run as one fused render, as parallel output ranges, or through materialized clips ( Yan et al., 2026b ; Yan et al., 2026a ) . Parallel ranges can repeat decoding and add intermediate traffic. Materializing clips spends local compute to change later input access. Source layout, cache state, and interference determine which plan delivers fastest, even across executions with the same visible task and hardware description. When hidden runtime conditions can reverse plan ordering, identifying the faster plan requires firsthand execution in the target setting. Execution-guided search uses measured performance to revise systems algorithms ( Cheng et al., 2025 ; Hamadanian et al., 2025 ) , storage configurations ( Egersdoerfer et al., 2026 ) , and serving policies ( Jiang et al., 2026b ) . Prior programs and measurements provide an initial cost estimate; the target setting’s physical response updates it. Under a fixed measurement budget, adaptation must also choose which comparisons will inform the next revision. Experiment selection connects harness evolution to task-aware exploration, which values information by its effect on downstream control ( Wagenmaker et al., 2023 ) . Active video investigation tests competing failure explanations before harness revision ( Luo et al., 2026a ) , while self-improving branches adapt the development cases used for search ( Dong et al., 2026 ) . We study whether selecting task–resource measurements can improve a successor’s physical execution policy. DeltaHarness extends this execution-guided loop to physical tool plans with fixed model weights and tool kernels. For a new device, workload, or resource setting, cold start combines inherited programs and experience with measurements of its current physical response. The physical policy chooses partitioning, concurrency, fusion, and materialization. The dispatcher uses measured delivery times to update admission decisions, and selects task–resource comparisons for the next proposal. An independent common panel determines incumbent replacement. Figure 1 shows how experience in the target setting informs these revisions. Program-level recursive self-improvement also makes the improver itself an optimization target ( Srikanth et al., 2026 ) . Our recursive variant rewrites its evidence-analysis program, while policy self-evolution updates . We compare learned experiment allocation with uniform and balanced panels under matched budgets, followed by frozen held-out evaluation to assess transfer ( Wang et al., 2026b ; Xia et al., 2026 ) . In the fixed-dispatch video-editing case, materializing clips before fusion reduces latency by 30.0% and raises average active FFmpeg cores from 0.95 to 1.80. On held-out tasks, the first policy-search seed beats the best fixed plan and the second improves its initial proposal. Additional comparisons examine experiment selection, resource response, and orchestration.
