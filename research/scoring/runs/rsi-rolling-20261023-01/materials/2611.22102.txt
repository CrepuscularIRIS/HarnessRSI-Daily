arXiv: 2611.22102    title: EvoDisco: Strategy Discovery for Evolving Agent Memory

[abstract]
Large language model agents accumulate experience in memory, and how that memory evolves during interaction is as important as what it stores. Recent methods update memory online, yet both the operators that transform memory and the rules that select them remain fixed by design. We propose EvoDisco, which formulates agent memory evolution as evolutionary strategy discovery: the agent must discover which operator to apply, when to apply it, and how to instantiate it, rather than rewriting memory under a static operator schedule. A learnable policy conditions on the current memory state and recent task history, then selects and instantiates one of four semantic operators---Abstract, Refine, Bridge, and Reframe---which respectively compress related memories, decompose overloaded entries, connect weakly linked experiences, and reorganize retrieved reasoning chains. The policy is updated with a bi-level fitness. An inner signal scores each transformation using a retrieval-quality improvement regularized by memory complexity. An outer signal scores strategic efficacy over a window of past decisions, combining historical operator-utility regret, utility-prediction error, and selection diversity. Under a one-pass online plus frozen-transfer protocol on ALFWorld, WebShop, and LifelongAgentBench (OS and DB), EvoDisco improves over strong memory baselines including MemP and MemRL. The largest gains are on ALFWorld ($+8.8$ online / $+12.9$ frozen-transfer points over MemP; $+16.4$ / $+17.9$ over MemRL). Ablations attribute these gains to both fitness levels and the operator library.

[intro/head from cached fulltext]
Large Language Model (LLM)-based agents have emerged as a powerful paradigm for tackling complex, long-horizon tasks that require reasoning, planning, and multi-turn interaction. However, effective agency in such settings demands more than the ability to solve isolated prompts—agents must accumulate experience, retain task-relevant information across sessions, and selectively reuse past knowledge. This requirement exposes a fundamental limitation of context-only interaction: even with long-context models, relevant information can be diluted or forgotten as interactions grow, leading to unstable recall and degraded reasoning performance. Memory systems have thus become a core module in LLM-based agents. Recent work has increasingly recognized that how memory is organized matters as much as what is stored. A growing body of research has moved beyond flat vector retrieval toward structured memory representations, particularly knowledge graphs, which offer superior capabilities for modeling inter-memory relations, enabling multi-hop reasoning, and providing interpretable access. Representative systems include AriGraph [ 1 ] , which integrates semantic and episodic memories within a unified knowledge graph; Zep [ 2 ] , which provides a temporal knowledge graph architecture for agent memory; A-MEM [ 3 ] , which adopts a Zettelkasten-inspired interconnected knowledge network; and G-Memory [ 4 ] , which employs a hierarchical graph-based memory design. These graph-based approaches have demonstrated significant advantages over unstructured memory in tasks requiring structured access and associative retrieval. Despite these advances, a critical limitation persists across existing memory systems: the memory structure itself remains static after its initial construction . Most structured memory mechanisms rely on one-time restructuring workflows to build their memories, neglecting ongoing updates and optimization of the memory structures. An advanced agent should progressively enrich and refine its memory structure throughout interactions with the environment. While some recent works have begun to address memory evolution—for instance, HAGE [ 5 ] employs reinforcement learning to drive weighted graph evolution, and MemEvolve [ 6 ] introduces a meta-evolutionary framework that jointly evolves experiential knowledge and memory architecture—these approaches still rely on fixed evolutionary operators (e.g., mutation and crossover with predetermined probabilities) or manually engineered adaptation mechanisms . This raises a fundamental question: If the agent itself is capable of reasoning about its own memory, why should the way memory evolves be predetermined by human designers? In this paper, we propose EvoDisco (Strategy Discovery for Evolving Agent Memory), a novel framework that elevates agent memory evolution from rewriting memory under a fixed operator schedule to discovering how memory should evolve . Unlike prior work that treats evolution as a blind search using fixed genetic operators, EvoDisco enables the agent to discover which evolutionary operation to apply, when to apply it, and how to instantiate it based on the current memory state and recent task performance. The agent maintains a strategy policy —a learnable module that selects from a curated cognitive operator library (abstraction, refinement, bridging, and reframing)—and the policy itself undergoes evolution guided by a bi-level fitness function that evaluates both the immediate utility of each operation and the strategic efficacy of the agent’s historical decisions. Figure 1 gives an overview. Our contributions are threefold: • Evolutionary Strategy Discovery. We formulate memory evolution as a learnable strategy-selection problem, shifting from a fixed operator schedule to state-conditioned selection and instantiation of semantic memory transformations. • Bi-Level Fitness with Strategic Efficacy. We introduce a dual fitness framework that evaluates the retrieval-quality change and structural cost of each memory update, together with the policy’s historical accuracy in selecting high-utility operators. • Cognitive Operator Library. We design a curated set of four semantic-level operators— Abstract (compressing related memories into higher-level concepts), Refine (decomposing overloaded memories), Bridge (connecting weakly linked experiences), and Reframe (reorganizing retrieved reasoning chains)—that provide sufficient expressive power while maintaining controllability. Through extensive experiments on ALFWorld, WebShop, and LifelongAgentBench (OS and DB), we evaluate the learned policy against fixed-strategy and memory baselines.
