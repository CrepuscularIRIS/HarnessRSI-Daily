arXiv: 2611.22583    title: Evolution Under Fire: Evolving Agent Safety Harnesses with Adaptive Injection Stressors

[abstract]
Tool-using language-model agents must act on information from untrusted emails, webpages, and documents. This creates a central security challenge: malicious instructions and legitimate task directives can arrive through the same interaction channel. Existing defenses are largely hand-designed and static, making further improvements dependent on repeated manual redesign. We introduce Evolution Under Fire, a staged framework that couples safety-harness evolution with adaptive stressor evolution. Utility-constrained, Pareto-scheduled tree search evolves complete executable safety harnesses from execution evidence while keeping the task model, benchmark, tools, and evaluator fixed. Adaptive stressor evolution then discovers utility-preserving attacks that guide a subsequent stage of harness evolution. On AgentDyn with GPT-4o-mini, an evolved harness reduces attack success from 50.4% to 3.0%, improves clean and attacked utility over the initial harness, and offers a stronger security-utility trade-off than reproduced defenses. On Agent-SafetyBench with Qwen2.5-7B-Instruct, harness evolution reduces attack success from 82.6% to 62.0% while retaining helpfulness and runtime validity. Evolved harnesses also transfer without further evolution to Qwen3.5-35B-A3B, reducing attack success from 32.1% to 0.9% while improving attacked-task utility.

[intro/head from cached fulltext]
Language-model agents increasingly complete user requests by reading emails, webpages, repositories, and other external content before invoking consequential tools. The same interface that makes these agents useful also creates an indirect prompt-injection channel: an attacker can place instructions in data that the agent later treats as authority ( Greshake et al., 2023 ; Debenedetti et al., 2024 ; Zhan et al., 2024 ) . The resulting failure is not confined to an unsafe response. It can change a tool call, disclose private data, or commit an external side effect. Defending this setting exposes a difficult security–utility trade-off. Prompt reminders and content filters can suppress attacks but also discard instructions that are legitimately required by open-ended tasks. Conversely, permissive agents preserve utility while remaining vulnerable. Recent system-level defenses introduce planning constraints, information-flow rules, privilege policies, causal monitors, or action auditors ( Debenedetti et al., 2026 ; Shi et al., 2025 ; Li et al., 2025 ; Zhu et al., 2025 ; Wang et al., 2026c ; Wang et al., 2026a ; Ma et al., 2026b ) . Each design encodes a useful hypothesis, but each is a fixed point in a large program space: the surrounding harness can choose how to construct context, expose tools, maintain state, invoke auxiliary models, validate actions, and recover from uncertainty. At the same time, a fixed attack suite is an incomplete optimization signal. AgentDojo provides executable tasks and security oracles ( Debenedetti et al., 2024 ) , while AgentDyn adds open-ended tasks whose legitimate completion can depend on external instructions ( Li et al., 2026 ) . Yet repeatedly optimizing against the same attack family risks producing benchmark-specific defenses. Adaptive attack work shows that static evaluations can overestimate defense efficacy when attacks are adapted to the target defense ( Ma et al., 2026a ) . This suggests that neither side should remain a single hand-designed artifact: the safety harness should improve from its failures, and the attacks used to probe it should improve as well. This raises the central question of this paper: How can executable safety harnesses evolve from observed failures, and how can adaptive, utility-preserving attacks further strengthen their defenses? In response to this question, we propose Evolution Under Fire , a framework that places safety-harness evolution under adaptively generated injection pressure while keeping the task model and benchmark fixed. The defense-side process is utility-constrained, Pareto-scheduled harness tree evolution . Each expansion selects one utility-qualified parent and produces one child harness, while a scheduler can revisit any previously evaluated branch rather than committing to a linear chain. Candidates that violate utility constraints cannot become parents, but remain visible as negative evidence. The attack-side process is utility-preserving, lineage-based stressor evolution . It opens or continues stressor lineages against cases a target harness originally solved securely, and retains a generated stressor as feedback only when the attack succeeds without destroying the benign task. Together, the two searches form a staged adversarial bootstrapping process: evolved harnesses guide the discovery of stronger stressors, which in turn strengthen subsequent harness evolution. Our contributions are: • Executable safety-harness evolution. We formulate agent defense as search over complete executable harnesses within a fixed evaluation environment. A read-only Diagnoser and code-generating Expander ground each edit in execution traces and archive-wide search history. • Utility-constrained Pareto tree search. Harness evolution admits only candidates that preserve utility relative to the initial harness, then samples parents from the Pareto frontier using uncertainty-aware metric estimates. It maintains diverse security–utility trade-offs, allows strong older branches to receive further expansions, and retains utility-rejected candidates as counterexamples without allowing them to propagate. • Feedback from adaptive stressors. Our stressor evolution generates adaptive stressors whose outcomes are verified by benchmark oracles. These adaptive stressors expose residual weaknesses in strong harnesses and provide targeted feedback for subsequent defense evolution. Stressor-guided evolution improves the security–utility frontier over a budget-matched harness-only control, and the resulting defenses transfer across closed and open-weight task models.
