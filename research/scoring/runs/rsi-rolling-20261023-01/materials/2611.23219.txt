arXiv: 2611.23219    title: Do LLM Agents Still Need to Be Told How to Self-Improve?

[abstract]
LLM agents increasingly drive their own learning. Self-improvement methods delegate various components of model optimization to the models themselves. As models become more capable, this motivates a basic question: do these increasingly capable models still need us to specify how they should self-improve? In this paper we study an autonomous paradigm in which, given basic primitives, resources, and a general goal for self-improvement, agents construct their own self-learning algorithm for context-based optimization. Using the setting of gameplay as a testbed, a frozen LLM agent is given a compute budget and tools for collecting experience and updating text documents, and allowed to freely experiment without an externally imposed loop or access to real-world data. We find that sufficiently capable models do self-improve under these conditions, demonstrating strategies that align with classic cognitive frameworks for self-regulated learning and constructs from machine learning literature on self-generated curricula. Furthermore, we study the extent to which the learned text artifacts transfer to external benchmarks, observing improvement across different game horizons, mechanics, and 3D navigation.

Imagine giving an agent a computer, and asking it to improve its ability to play puzzle games. What will it do? The computer has no pre-installed games; the agent must write its own games if it wants to practice. It must decide what sorts of games to try, which lessons to retain, and how to measure its progress. These decisions concerning the design of learning procedures are typically made by human practitioners. Yet as LLM agent capabilities improve, we increasingly delegate the machine learning process to the learners themselves. Various works leverage models to generate supervised data, construct interactive environments, and even rewrite their own tools and harnesses ( ???? ). In parallel with efforts to develop better methods, there are growing concerns about the need for safeguards against misaligned self-improvement. Both directions motivate a basic question: Do capable models still need us to specify how they should self-improve? We study the natural behavior of an LLM agent when provided with the primitive tools and resources for self-improvement via context manipulation, but without being wrapped in an explicit self-improvement algorithm. Rather than designing a loop for experience generation and learner updates, we allow the agent to compose actions into a self-learning procedure. The agent does not have access to real-world tasks or validation scores. It must experiment with different ways of generating tasks, reflecting on failures, and assessing progress in a constrained sandbox. Our setting is important for understanding both capability , where models may no longer require prescribed self-optimization algorithms, and safety , where the absence of a specified loop does not necessarily prevent self-improvement. We find that sufficiently capable models successfully self-organize learning procedures and self-improve on held-out tasks. We examine this phenomenon in the setting of gameplay with limited information. A player agent plays turn-based games with undisclosed mechanics under strict compute and game-horizon budgets. This task requires diverse reasoning skills including efficient exploration, information acquisition, multi-step planning, and world modeling. An instance of that same agent serves as the teacher . The teacher is given a general goal to improve the player through text (e.g., editing the prompt, creating skill files), a compute budget, and a set of tools for observing the player attempt self-generated games and editing player context. We do not instruct the teacher when to use the tools; the teacher freely experiments with the player. Across the set of effective self-learners, models from different families employ similar recurring, recognizable learning strategies, such as generating games with calibrated difficulty, running controlled A/B comparisons, and developing validation suites to measure progress. These strategies align to behaviors described by social-cognitive frameworks for self-regulated learning ( ?? ). We also find that agents spend more effort on harder tasks, resembling learnability objectives in asymmetric self-play ( ??? ). Furthermore, the self-constructed learning procedures generalize: Learned text files transfer across multiple benchmarks that require reasoning over different game horizons, engines, and representations. We study how providing information on evaluation settings to the teacher, via context or environment constraints, shapes this downstream generalization. Our main findings are: 1. Given just primitive tools for self-improvement via context manipulation, a sufficiently capable agent constructs an effective learning procedure that improves its own performance on held-out gameplay. 2. Models from different families implement recognizable strategies that align to self-regulated learning frameworks, and machine learning literature on self-generated curricula. 3. The learned text generalizes across game benchmarks and representations. Evaluation-setting awareness biases the teacher towards relevant tasks, however can encourage overfitting.
