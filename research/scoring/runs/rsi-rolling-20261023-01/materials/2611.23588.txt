arXiv: 2611.23588    title: ARISE: Practical Self-Evolving Memory for Accurate and Cost-Efficient Enterprise Agents

[abstract]
Enterprise LLM agents operate in dynamic environments where foundation models evolve rapidly, workflows update frequently, and deployments need to satisfy accuracy and cost requirements. We propose ARISE (Agent Refinement through Iterative Self-Evaluation), a practical memory architecture in which the agent's memory evolves from its own failures without updating model weights, tools, or workflow logic. ARISE uses the model itself or a teacher model to attribute the failures and propose corrections. Then, ARISE keeps the corrections as retrievable micro memory, consolidates them into macro rules, and accepts a rule update only if held-out accuracy rises. Across 14 enterprise-workflow domains from SOP-Bench and $τ^2$-bench using 5 models, ARISE-Teacher, which uses Claude Opus 4.6 for attribution and consolidation, gains 10.9 pp over the baseline on SOP-Bench and 5.8 pp on $τ^2$-bench. ARISE-Teacher also outperforms GEPA by 4.5 pp on $τ^2$-bench and 1.4 pp on SOP-Bench. With the deployment model as its own attributor, ARISE-Self still gains 10.0 pp on SOP-Bench. ARISE-Teacher uses 4.0% fewer model calls and 5.2% fewer output tokens at comparable per-task cost (-1.0%).

[intro/head from cached fulltext]
Enterprise agents run on rapidly evolving LLMs, with new state-of-the-art models appearing monthly. Standard operating procedures (SOPs) and policies change, requiring corresponding updates to agents. Model and workflow changes occur independently, requiring teams to revalidate agents rather than rely on a one-time prompt update. Rebuilding agents for these changes requires development and maintenance effort. Each task has a cost budget, so longer prompts incur cost on every request. Existing methods improve agents from experience through reflection ( Shinn et al., 2023 ) , insight extraction ( Zhao et al., 2024 ) , or prompt and context evolution ( Agrawal et al., 2026 ; Zhang et al., 2026 ) . Model training ( Srivastava et al., 2025 ) additionally requires access to model weights. Many enterprise workflows expose verifiable post-task outcomes, such as whether a customer request reaches its intended system state or an SOP execution returns the correct decision. ARISE is a practical memory architecture that self-evolves while model weights, tools, and workflow logic remain fixed (Figure 2 ). The offline loop uses task traces, agent outputs, and post-task feedback to diagnose failures. It collects failed training tasks with their expected outputs or diagnostic feedback, asks an attributor to write scoped corrections, stores them as micro memory, and consolidates them into at most macro rules. A held-out validation gate accepts a rule update only when accuracy improves. At inference, the agent receives the macro rules and the most similar corrections. A stronger LLM can serve as the teacher, while the deployment model can perform attribution and consolidation itself; the latter setting gains 10.0 pp on SOP-Bench. Our contributions are threefold. First, we propose a dual-memory architecture that adapts a deployed agent from its own failures without retraining the model. The bounded rule set keeps the injected memory compact and directly inspectable before deployment. Micro memory preserves corrections, macro memory consolidates general guidance, and a held-out gate controls rule updates. The same loop can be rerun when the workflow or deployment model changes. Second, across 14 enterprise-workflow domains using 5 models, ARISE-Teacher improves over the baseline and GEPA while using 4.0% fewer model calls and 5.2% fewer output tokens than the baseline (Tables 2 and 10 ). Third, we provide deployment guidance on the sources of the gains, the choice of attributor, and the behavior of the validation gate (§ 5 ).
