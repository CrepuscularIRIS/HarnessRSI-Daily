arXiv: 2611.24004    title: Space-X: Self-Evolving Spatial Agents Weaving Clues into Evidence Chains

[abstract]
Spatial reasoning connects visual observations, geometric estimates, and linguistic decisions into a coherent derivation. Yet tool-augmented agents often acquire evidence without clear targets, combine outputs under inconsistent object or reference-frame semantics, and misjudge evidence sufficiency. Thus, more tools or calls do not reliably improve reasoning. We introduce Space-X, a spatial-reasoning framework that self-evolves toward complete, continuous evidence-chain construction. An Execution Agent acquires, associates, and judges evidence per problem using role-specific memory. A Control Agent diagnoses evidence-chain breaks from execution traces and jointly revises tools, interfaces, skills, memory organization, and decision rules. This loop co-evolves capability and evidence use: evidence needs guide capability development; usable results guide actions. Across multiple benchmarks, Space-X yields gains with four base models. Relative to baselines, GPT-6-sol improves answer accuracy on ViewSpatial and MMSI by 50.39% and 23.07%, respectively; Gemini-3.8-Flash gains 47.50% and 25.22% on these benchmarks. This provides a unified route from fragmented spatial clues to traceable, derivable answers.

“ Standing beside the chair and facing the door, where is the table? ” Answering such a question requires language, vision, and geometry to meet in one decision. The chair defines the observer position, the door defines the facing direction, and the table defines the target. Images from different viewpoints provide partial observations; spatial computation expresses those observations in the frame specified by the question; and the final answer follows from the resulting directional relation. Object recognition, geometric estimation, and language reasoning play distinct roles, but they must be connected by a continuous evidence chain that starts from the question, remains grounded in observations, and ends at the answer. Recent spatial agents extend vision-language models with perception tools, executable skills, and memory, improving object grounding, geometric computation, and multi-step problem solving [ 28 , 42 , 43 , 12 ] . In complex tasks, however, these capabilities are still disrupted by three recurring breaks, as summarized in Fig. 1 . Untargeted evidence acquisition repeatedly detects or reconstructs the scene while missing a required target, observer position, facing landmark, or measurement endpoint; the corresponding evidence need also fails to guide the addition or selection of tools. Inconsistent evidence interpretation directly combines results from different instances, views, scales, or reference frames, or loses their provenance during memory and context handoff. Misjudged evidence sufficiency produces an answer before the necessary relations are established, or continues gathering observations until no budget remains for review. These failures break the transitions from needs to tools, results to evidence, and evidence to answers. Consequently, expanding the tool library or increasing the number of calls alone does not yield stable gains. The underlying difficulty is a mismatch between human-designed execution structures and the model’s actual weaknesses. A designer may prescribe which tools to call and in what order, expecting the model to connect their outputs naturally. Yet the model may recognize local objects while failing to establish cross-view identity, read coordinates while using the wrong frame, or generate a plausible answer without knowing whether its premises are complete. A useful tool therefore needs more than an implementation: the agent must know when to select it, how to interpret its return value, where to preserve that result, how to associate it with other evidence, and when the accumulated support is sufficient. This motivates self-evolution driven by execution: evidence needs exposed during solving should determine how tools are added and selected, how memory preserves source-linked observations, how results are interpreted, and how the process advances toward an answer. We propose Space-X , a self-evolving agent framework for spatial reasoning that makes the construction of complete, continuous evidence chains the objective of framework improvement. The framework couples two complementary roles. The Execution Agent constructs the evidence chain for the current task through semantic grounding, evidence association, and evidence-grounded judgment . It identifies objects, frames, relations, and output units from the question; selects and combines tools according to unresolved premises; turns inspectable outputs into source-linked evidence; and decides whether to acquire more evidence, review a disputed premise, or answer. Five memory roles support this process: Working Memory tracks premises and gaps, Observation Memory preserves original views and crops, Spatial Memory stores objects and compatible geometric relations, Episodic Memory records actions and review history, and Procedural Memory supplies reusable operating guidance. The Control Agent improves the execution structure offline. It reads execution feedback—claims, sources, task outcomes, failures, and resource use—to diagnose the broken evidence link. It then co-designs capability and use by revising tools and interfaces together with source semantics, memory destinations, context delivery, review triggers, and closure rules. Candidate changes are compared against the current structure, checked at both the evidence-chain and task levels, and retained only when their downstream use is explicit. Thus, tool expansion, tool selection, and result use form a mutually driven process: evidence needs guide capability development, and usable results guide the next action . Each execution converts available capability into an evidence chain; each iteration makes the execution structure better match the model’s subsequent reasoning needs.
