arXiv: 2611.26806    title: MedicalRSI: Medical Recursive Self-Improving Agents via Clinical Model-Harness Co-Evolution

[abstract]
Medical agents built on large language models (LLMs) have advanced rapidly, yet most stay fixed once deployed and do not keep using their experience to improve later attempts. As a result, the same kind of error can recur across patients. To address this, existing self-improvement methods update an agent's weights or its medical harness from its own experience, but their improving strategy stays fixed and never learns which changes actually help, which caps how much the agent can improve. Recursive self-improvement (RSI) instead improves both the agent and its improving strategy. However, achieving RSI for medical agents is challenging, because clinical workflows rarely come with a reference harness, and a change that fixes early errors may not fix the problems the agent meets later. We propose MedicalRSI, an RSI framework built on Clinical Model-Harness Co-Evolution, in which one model plays two roles. The Solver is the medical agent itself, and the Improver is its learnable improving strategy, which writes a medical harness from the agent's failures. Each harness is rewarded by its gain over acting without it, and both roles are trained together, so the Improver keeps adapting to the problems the Solver has not yet solved. On multiple benchmarks and LLM backbones, MedicalRSI outperforms existing context-level and weight-level self-improvement methods and transfers well to unseen workflows, new LLMs and new databases, a step toward medical agents that keep improving.

[intro/head from cached fulltext]
Medical agents built on large language models (LLMs) now assist clinicians in diverse settings ( Tang et al., 2024 ; Kim et al., 2024 ; Wang et al., 2025b ; Wang et al., 2026d ; Zhao et al., 2026 ) . On an electronic health record (EHR) system, for example, an agent can retrieve laboratory results, record patient information and place orders ( Jiang et al., 2025 ) . In practice, clinical workflows involve recurring checks and decisions across patients, so experience gained from one attempt can guide later cases. Yet most medical agents stay fixed once deployed and do not keep using this experience to improve later attempts ( Feng et al., 2022 ; Fang and others, 2025 ; Gao et al., 2025 ; Zhu et al., 2026 ; Zhang et al., 2026c ) . As a result, the same kind of error can recur across patients ( Xu et al., 2026a ; Feng et al., 2025 ) . To use this experience, recent work has made medical agents improve themselves along two routes. Weight-level methods train the underlying LLM on the results of the agent’s own attempts ( Xu et al., 2026a ; Feng et al., 2025 ; Chen et al., 2026a ; Liu et al., 2026a ) , while context-level methods update the medical harness, including the skills, tools and memory that support clinical workflows ( Li et al., 2024 ; Shen et al., 2026b ; Han et al., 2026 ; Moll et al., 2026 ; Wu et al., 2026 ) . In both routes, an improving strategy determines how execution experience is turned into changes to the model or the harness, such as how training examples are selected or how an LLM revises the harness based on failures. However, the improving strategy in these methods stays fixed. Because this strategy never learns which of its changes actually help the agent, it caps how much the agent can improve. For example, on MedAgentBench, a 9B agent solves 51.6% of the tasks with harnesses generated by the frontier LLM GPT-6.1-Sol , compared with 61.2% when the harnesses are generated by a 9B model trained on the agent’s own outcomes (Figure 1 ). This gap, in line with prior work ( Yao et al., 2024 ; Shao et al., 2026 ; Ouyang et al., 2026a ) , shows that learning how to improve can itself yield further gains. This motivates recursive self-improvement (RSI), in which an agent improves not only itself but also its improving strategy ( Good, 1965 ; Schmidhuber, 2003 ; Yin et al., 2025 ; Zhang et al., 2026a ) . However, realizing RSI for medical agents is challenging. To get better, the improving strategy needs to know which of its changes actually help the agent. Clinical workflows rarely come with a reference harness that tells the agent how to organize its steps, and the details of execution also vary with each hospital’s procedures and systems ( Finlayson et al., 2021 ) . The improving strategy must therefore learn from the outcomes of the agent’s attempts to judge whether a proposed change works. What makes this harder is that a change that fixes early errors may not fix the problems the agent meets later. For example, a magnesium replacement task requires the latest laboratory result within the last 24 hours and a replacement dose based on the magnesium level. The agent mistakenly uses a result from three days ago and so fails to place a necessary order. At this point, a skill that makes the time filter an explicit step in the harness helps the agent correct this retrieval error. Once the agent has learned to filter results correctly, however, it retrieves the correct result but selects the wrong dose, and the same change no longer helps. As a result, the improving strategy must not only learn from the agent’s outcomes but also keep adapting as the agent learns, so that its changes can target the problems the agent has not yet solved. This leads to the central question of this paper: How can a medical agent continually improve its improving strategy from its own outcomes? To answer this question, we propose MedicalRSI , a recursive self-improvement framework for medical agents (Figure 2 ). At its core is Clinical Model-Harness Co-Evolution , in which one model plays two roles. The Solver is the medical agent itself, which carries out a clinical workflow on each patient’s records by following a medical harness. The Improver is its learnable improving strategy, which writes this harness from the agent’s failures. Because no reference harness exists, each harness is rewarded by how much it improves the agent’s outcomes over acting without it, so the Improver learns which changes actually help. Both roles are trained together on the same attempts. The Improver thus keeps adapting to the problems the Solver has not yet solved, while the Solver learns to carry out the workflow with the harness. On a new workflow, the same model writes a medical harness from a few failures at test time, without retraining. Our contributions are as follows: • Framework.
