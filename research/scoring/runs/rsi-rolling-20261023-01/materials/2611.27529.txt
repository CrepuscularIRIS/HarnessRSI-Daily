arXiv: 2611.27529    title: Fix Where It Fails: Root-Cause-Guided Agentic Harness Optimization for Scene Graph Generation

[abstract]
Scene graph generation (SGG) aims to detect objects in an image and predict the relationships between them. The standard PredCls, SGCls, and SGDet settings show how much performance drops without ground-truth boxes and labels, but not where or why a model fails. Knowing this would allow fixing a model where it fails, without retraining. We propose RoHa-SGG (Root-cause-guided Harness optimization for SGG), which extends agentic harness optimization to SGG. It optimizes the harness, the inference code around a frozen SGG model. RoHa-SGG has two main LLM agents. A root-cause analysis (RCA) agent finds the components where the model fails and diagnoses why, and a proposer agent searches for a harness that fixes these causes. We evaluate RoHa-SGG on Visual Genome and PSG with representative two-stage, one-stage, and multimodal-LLM SGG models. The analysis shows that the components where ground-truth triplets are lost differ across models and datasets. RoHa-SGG improves every metric on all five model-dataset combinations. Graph-constrained R@100 and mR@100 rise by up to 15.8 and 26.4 points for the multimodal LLM and by up to 3.6 and 10.1 points for the two-stage and one-stage models. With root-cause guidance, the harness search reaches the final score of an unguided search up to three times faster.

Scene graph generation (SGG) describes an image as a set of (subject, predicate, object) triplets, such as (man, riding, horse), over the objects it contains [ 51 , 22 ] . Most SGG models follow one of three architectures: two-stage models first detect objects and then classify a predicate for each candidate pair (REACT++ [ 34 ] ), one-stage models predict objects and predicates together in a single DETR-style pass [ 6 ] (EGTR [ 18 ] ), and multimodal large language models (MLLMs) write the whole graph as text (R1-SGG [ 8 ] ). Whatever the architecture, a ground-truth triplet counts as a match only if it passes five components: a correct box and name for both objects, a proposal for the pair, the correct predicate, and a rank within the top . SGG is usually evaluated in three settings [ 51 ] , which give the model ground-truth boxes and labels (PredCls), boxes only (SGCls), or neither (SGDet). Comparing the three shows how much a model depends on the given boxes and labels, but not at which component it loses ground-truth triplets. A model can fail at any of the five components, and where it fails differs by model and dataset ( Fig. 1 , left). Following TIDE [ 3 ] and Diag-HOI [ 63 ] , we measure this with the same procedure for all three models. We correct components with their ground truth (the true boxes, names, pairs and predicates, and an ideal ranking) and attribute the recovered recall to each component ( Fig. 3 ). In graph-constrained ( gc ) R@20, the missed ground-truth triplets spread over several components, and REACT++, EGTR and R1-SGG all lose the most at the pair component. On VG150, the MLLM R1-SGG also loses 27.9 points at the box component, against 7.5 for each classic model. R1-SGG loses nothing at the rank component, where the classic models lose 11.6 to 16.5. On PSG, REACT++ and R1-SGG both lose more at the predicate component than on VG150 (19.6 and 16.6 vs. 16.1 and 9.7 points). A method that targets a single component therefore recovers only part of the missed triplets, and one that helps one model or dataset may not help another. Earlier SGG analyses measure only parts of this, such as pair recall [ 46 ] , what the detector can reach [ 37 ] or separate object, pair and predicate scores [ 30 ] , or substitute ground truth in a fixed order [ 14 ] . The weaknesses these analyses reveal are then usually fixed by retraining the model, for example with a new pair proposal module [ 46 ] . Retraining, however, is costly and must be repeated for every model and dataset. We instead optimize the harness , the inference code that prepares the model’s input, calls the model, runs external tools, and post-processes and ranks the output. Because it handles every step from the image to the final scene graph, the harness can reach every component without changing the model. Harness optimization has recently been shown to work for LLM systems [ 24 ] and, in concurrent work, for video understanding and embodied agents [ 28 , 23 ] . It has not yet been applied to SGG. The space of possible harnesses is large, and scoring each candidate harness means running the model on a large image set. The search is therefore expensive and can afford only a few candidates. These few candidates should target where the model actually fails. Recent harness optimizers diagnose failures by reading an LLM agent’s execution traces, such as its prompts, tool calls and intermediate reasoning [ 7 , 36 , 47 ] . A frozen SGG model produces no such trace. Its output shows which ground-truth triplets are missing, but not where or why they were lost. We therefore measure where, component by component, and then test why. We introduce RoHa-SGG ( Ro ot-cause-guided Ha rness optimization for SGG ), which uses this per-component diagnosis to guide the harness search ( Figs. 1 and 2 ). It has two LLM agents. A root-cause analysis (RCA) agent finds where and why the model loses ground-truth triplets, using the same procedure for every model and dataset. It splits the missed triplets over the five components with Shapley values and tests each suspected cause with an intervention whose effect it predicts before running it. A proposer agent then searches for harnesses that fix the diagnosed causes first, rather than exploring the code space without direction. The search runs in rounds, and before each round the RCA agent analyzes the current best harness again, so the proposer always works on the causes that remain. We evaluate RoHa-SGG with REACT++, EGTR and R1-SGG on VG150 [ 22 , 51 ] and PSG [ 52 ] . Without retraining the SGG models, the harness found by each search improves every metric on the official test sets of all five model–dataset combinations ( Tab. 2 ). gc R@100 and mR@100 rise by up to 15.8 and 26.4 points for R1-SGG and by up to 3.6 and 10.1 points for REACT++ and EGTR.
