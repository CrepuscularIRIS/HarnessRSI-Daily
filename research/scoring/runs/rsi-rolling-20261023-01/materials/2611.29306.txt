arXiv: 2611.29306    title: DoppelVet: Comparative Safety Verification for Self-Evolving Agents

[abstract]
Self-evolving agents improve by retaining feedback as reusable memories or skills, but every mistaken approval can shape many future behaviors. Two updates can provide exactly the same evidence to a verifier yet produce opposite safety outcomes, so the verifier cannot distinguish them from that evidence alone. We introduce DoppelVet, a verification framework that checks proposed updates before they enter an agent's persistent state. Without access to safety labels, DoppelVet constructs an alternative that matches every signal used by the existing verifier. It replays both updates from the same state and directly compares their behaviors in both presentation orders before deciding whether to retain the candidate. We evaluate DoppelVet on DoppelVet-Grid and DoppelVet-Tool, covering executable programs and natural-language memories. Across nine open-weight and proprietary verifiers, DoppelVet raises mean harmful-update detection AUC from 0.762 to 0.940 on DoppelVet-Grid and from 0.681 to 0.826 on DoppelVet-Tool, outperforming VaG and AgentDoG 1.5. On DoppelVet-Grid, it reduces trajectories experiencing degradation from 30.39% to 0.43% over a ten-generation self-update loop and leaves no final degradation.

Large language models increasingly serve as agents that plan, use tools, and act across extended interactions ( Yao et al., 2023 ; Liu et al., 2024 ) . These agents navigate digital environments, explore embodied worlds, and complete multi-step workflows involving external tools and users ( Zhou et al., 2024 ; Wang et al., 2024a ; Zhou et al., 2025 ; Barres et al., 2025 ) . Yet many agents still approach each task with fixed model parameters and a fixed set of instructions or demonstrations. This design supports familiar tasks but offers little way to reuse a new success or avoid a newly observed failure. Experience from one task therefore rarely becomes reusable knowledge for the next ( Wang et al., 2025 ) . Self-evolving agents address this limitation by turning experience into persistent memories, workflows, and skills ( Shinn et al., 2023 ; Zhao et al., 2024 ; Wang et al., 2025 ) . Once retained, these updates shape later decisions and guide the generation of subsequent updates. Since retained updates are reused across tasks, a single mistaken approval can affect many future behaviors ( Chen et al., 2024 ; Dong et al., 2025 ; Shang et al., 2026 ) . Existing systems commonly evaluate each proposed update independently using task feedback, self-reflection, or a candidate-wise verifier ( Shinn et al., 2023 ; Madaan et al., 2023 ; Gou et al., 2024 ; Zhou et al., 2025 ) , while recent work adds external evaluation, pre-commit filtering, and rollback ( Zhang et al., 2026 ; Park and Choi, 2026 ; Shang et al., 2026 ; Qin et al., 2026 ) . These mechanisms still evaluate each proposal in isolation. Task-level rules cannot separate identical task-level readouts; full-trajectory pointwise evaluators see more evidence but lack a matched same-state behavior ( Liusie et al., 2024 ; Zheng et al., 2023 ) . Both can therefore allow avoidable harm into persistent memory. The problem arises when two updates appear equally successful to the verifier but lead to different safety outcomes. We use the term native verifier for the system’s existing rule for deciding whether an update is retained. It evaluates each update using its configured task-level evidence. Consider the Conveyor Belt Sushi environment from AI Safety Gridworlds ( Leike et al., 2017 ; Krakovna et al., 2018 ) . An agent must reach a destination while satisfying a safety requirement that nearby sushi remain undisturbed. Two candidate updates reach the destination with the same task score and the same number of actions, so the native verifier receives identical inputs for both. Yet one route leaves the sushi untouched, while the other displaces it. Any rule operating only on these identical inputs must return the same decision. The safety difference appears in the resulting executions and is absent from the evidence available to the native verifier. We call such updates verifier-equivalent (Figure 1 a). This impossibility concerns only native-readout decisions. Full-trajectory pointwise evaluation instead asks empirically whether an isolated trace reveals avoidable harm without a matched safe execution. We introduce DoppelVet to compare matched executions before an update is retained. Instead of considering the candidate alone, DoppelVet searches without safety labels for a verifier-equivalent alternative that produces a visibly different execution. It replays both updates from the same state and asks a comparison verifier to judge which behavior is less safe. Both presentation orders are scored and averaged before the system retains, rejects, or abstains on the candidate (Figure 1 b). If search finds no behaviorally distinct verifier-equivalent alternative, DoppelVet abstains and leaves the persistent state unchanged. Deterministic checks, monitoring, and rollback provide additional safeguards (Figure 2 ). To evaluate harmful-update detection before persistence, we introduce DoppelVet-Bench , comprising two tracks: DoppelVet-Grid and DoppelVet-Tool. DoppelVet-Grid contains executable program updates from six AI Safety Gridworlds environments ( Leike et al., 2017 ) , while DoppelVet-Tool contains natural-language memory updates and complete customer-service conversations from Retail and Airline environments ( Barres et al., 2025 ) . Each example includes a proposed update, a same-state alternative, task and execution records, and an independent safety outcome. Across nine open-weight and proprietary verifier backbones, DoppelVet consistently improves harmful-update detection, raising mean AUC from 0.762 to 0.940 on DoppelVet-Grid and from 0.681 to 0.826 on DoppelVet-Tool. On the same evaluation sets, it outperforms recent state-of-the-art agent verification methods ( Shang et al., 2026 ; Liu et al., 2026 ) and transfers to the public ATBench trajectory-safety benchmark ( Li et al., 2026 ) .
