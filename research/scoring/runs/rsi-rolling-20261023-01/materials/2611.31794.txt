arXiv: 2611.31794    title: AGL-SKILL: Coding Harnesses as Agentic Optimizers

[abstract]
Frontier models are increasingly used through harnesses as agents, with growing autonomy to do useful work. Agent performance can often be enhanced by the use of skills: reusable workflows, code, and prompts that provide task-related information or guide the behaviour of the model. Skills, being textual in nature, present themselves as another editable surface to be optimized; current methods have improved on handcrafting and one-shot generation by treating skill development as an iterative process, using score-driven search to tweak and improve performance. In this paper, we demonstrate the efficacy of the agents themselves as optimizers: across five benchmarks, a coding agent without guidance substantially improves every target and outperforms published skill-optimization methods. More broadly, this shows the capability of agents to do such work and to refine their own behaviour to provide task-specific context, as long as they are given a metric to measure against.

[intro/head from cached fulltext]
Large Language Models (LLMs) are being applied to an increasingly diverse set of tasks, often through harnesses such as Claude Code or Codex to more effectively engage with the engineering environment. Harnesses provide models with tooling, context management, an execution environment, and subagent orchestration for them to better solve the problems they are working on; the combination of the two is commonly referred to as an agent and granted a large degree of autonomy in practice ( Anthropic, 2026a ) . Additional fine-grained context for individual users and tasks can be provided to agents on demand through skills (Figure 1 ), which are folders of instructions, scripts, and reference material ( Agent Skills, 2026 ) . How much a skill helps depends on these contents: whether by providing more nuanced information or more refined tooling built off an understanding of the problem space, some skills are better than others. The challenge, therefore, is to find a way to reliably develop skills that raise agent performance, whatever the task at hand. Several ways have been explored: the most direct is to handcraft the skill, but this is limited by its author and inflexible to a shifting task environment; more recent score-driven methods treat skill development as an optimization problem ( Yang et al., 2026 ; Alzubi et al., 2026 ) , using models to tweak the skill in a hill-climbing process that keeps only the edits which improve the score, and is inefficient as a result. Agents, by contrast, have a wider but directed search space, and already possess the tooling and environment to do this work. We therefore take the skill of a target agent as the object to be optimized, and set an optimizer agent to iterate on it, free to edit the rest of the target as well, guided by the target’s performance on the train split of a benchmark (Figure 2 ). We call this setup AGL-SKILL. To this end, we evaluate frontier models as agentic optimizers: two state-of-the-art models in three popular harnesses, at three budgets and on five benchmarks. Even without guidance, the agent is already a strong optimizer, outperforming every published method we compare against. Subsequently, we ask whether guidance improves on this by giving the optimizer the Agent Lightning skill – which is written for the optimization task itself – along with variants that use two-phase optimization, subagents, or Git worktrees. The answer is largely no: the skill and the variants occasionally raise the score, but none consistently beats the unguided optimizer by a notable margin. The skill is instead designed to set up the environment for a fresh agent with no prior context of the task. We also report the cost of each optimization and the test-time cost of the resulting target agent. A larger budget does not reliably buy a higher score, and the final score varies from run to run without tracking the optimization cost. The optimizer traces help explain why guidance adds so little: with or without it, the optimizers arrive at much the same solutions. These solutions are seldom far-fetched; making the target more robust is often enough to score highly, without recourse to an esoteric approach. The Agent Lightning skill is published in the Agent Lightning repository ( https://github.com/microsoft/agent-lightning ).
