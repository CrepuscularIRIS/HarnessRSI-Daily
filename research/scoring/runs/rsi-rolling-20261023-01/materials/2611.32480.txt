arXiv: 2611.32480    title: VISE: Verifier-Independent Skill Self-Evolution with Feedback from Tool Implementations

[abstract]
Agent skills provide reusable workflows that guide LLM agents in using tools. Refining these workflows requires feedback on missing or incorrect instructions, but task-specific verifiers are not always available. We propose VISE (Verifier-Independent Skill Evolution), a scripts-first approach that uses tool implementations to guide skill revision. It extracts tool capabilities, input requirements, usage conditions, and output formats from source code. Using the task request and execution trace, it compares this information with current workflow instructions to identify missing or conflicting steps. It then recommends specific edits to SKILL.md, linking each change to the relevant implementation and usage conditions. We evaluate VISE as an additional revision stage for four evolution methods on SkillsBench and SkillLearnBench. Compared with the corresponding No-verifier conditions, it improves overall average task success by 9.14-13.35 percentage points. The proportion of tasks solved in all three runs increases by 12.36-18.29 points. A case study shows how revised instructions connect tool outputs to later steps. These results support tool implementations as a practical feedback source for skill self-evolution.

[intro/head from cached fulltext]
Agent skills provide reusable procedures that help LLM agents use tools to complete tasks ( Zhang et al., 2025 ; Li et al., 2026 ) . Effective skills specify which tools to use, how to prepare their inputs, and how to use their outputs. For example, an object-counting workflow must explain which video frames to process and how to combine the returned counts. Without this guidance, an agent may call a tool without using its output to complete the task. Skill self-evolution refines such instructions through execution experience and feedback ( Zhang et al., 2026a ; Liu et al., 2026c ) . Feedback must therefore specify which instructions to revise and how. Existing approaches draw on model-generated feedback, execution experience, and task evaluation. Self-Refine uses self-feedback to refine outputs ( Madaan et al., 2023 ) , while SkillLearnBench studies self-feedback for skills ( Zhong et al., 2026 ) . Reflexion turns execution experience into verbal reflections that guide later attempts ( Shinn et al., 2023 ) . Verifier-based methods use success judgments or diagnostic reports to guide skill updates ( Zhang et al., 2026a ) . SkillRevise also re-executes revised skills to select the best observed candidate ( Liu et al., 2026c ) . Related work extracts procedural knowledge from code: Repo-To-Skill distills repository knowledge into reusable skills ( Chen et al., 2026 ) . When task-verifier feedback is unavailable, agents must determine how to revise skills from task requirements, tool implementations, and execution history. However, an available tool may support only part of a task or require inputs and conditions not covered by existing instructions. Effective revision therefore requires determining which tool capabilities apply to the task and how their requirements should shape the workflow. Agents must then identify where existing instructions omit necessary steps or conflict with the implementation, and translate those gaps into actionable revisions. We propose VISE (Verifier-Independent Skill Evolution), a scripts-first approach that uses tool implementations to guide skill revision. For new skills, it first selects or creates task-relevant scripts and then writes initial instructions in SKILL.md . For revision, it extracts information about tool capabilities, usage conditions, steps, and constraints, with references to supporting source code. It compares this information with the current instructions using the task request and execution trace. For each missing or conflicting step, it recommends a specific change and states when it applies. The revision stage updates the relevant passages in SKILL.md while retaining the scripts. This stage can also refine skills produced by other evolution methods. Figure 1 illustrates the approach. We evaluate VISE on SkillsBench and SkillLearnBench ( Li et al., 2026 ; Zhong et al., 2026 ) by further revising the No-verifier outputs of Self-Refine, TraceEvo, SkillLearn, and SkillRevise. Across the four methods, overall average task success increases by 9.14–13.35% over No-verifier. The proportion of tasks solved in all three runs improves by 12.36–18.29% (Table 2 ). VISE also exceeds the Binary, Report, and Diagnostic conditions on both overall metrics. A video-counting case study illustrates how revised instructions connect tool outputs to later steps. In a separate study, repeated evaluations show that similar overall gains can hide changes in which tasks benefit. Newly constructed SkillsBench variants further show that changing requirements can reduce or reverse the skill benefits observed on the original tasks. Our contributions are threefold: 1. Tool-grounded skill evolution. We propose VISE , which links information from tool implementations to missing or conflicting workflow instructions and generates targeted revision feedback. 2. A systematic comparison of feedback sources. We compare feedback sources across four evolution methods on SkillsBench and SkillLearnBench, measuring average task success, task coverage, and repeated execution success. 3. An empirical study of skill utility. Through repeated evaluations and task variants, we analyze which tasks benefit from skill use and how these benefits change with task requirements.
