arXiv: 2611.33119    title: MetaFORGE: A Meta-Learning Framework for Harness Optimization in Automated Code Generation for Parallel Computing

[abstract]
Large language models (LLMs) can generate parallel programs, but their correctness and performance depend strongly on the instructions that guide generation. We present \textsc{MetaFORGE}, an execution-grounded meta-learning framework that iteratively optimizes persistent natural-language skill specifications for MPI C code generation. \textsc{MetaFORGE} combines correctness testing, compiler diagnostics, static-analysis findings, runtime measurements, and rank-level load-imbalance profiles into a scalar reward that drives textual-gradient refinement, while an external memory distills and retrieves reward-supported optimization knowledge across runs. Across six MPI tasks and three workload sizes, \textsc{MetaFORGE} improves static-analysis quality, runtime, and load balance relative to zero-shot generation and generally exceeds the evaluated \textsc{TextGrad} iterative baseline. A model-matched refinement ablation shows that the MetaFORGE advantage persists when its refinement model is reduced to \texttt{gpt-4o}. An expanded retrieval ablation across all 18 task--workload configurations shows consistent runtime benefit and broad static-analysis and load-balance benefit from retrieved context. Leakage-controlled held-out and zero-update experiments further provide evidence that optimization knowledge persists in both the transferred skill and external memory under the evaluated protocol.

LLM-based code generation remains difficult because informal or semi-formal requirements often contain ambiguities in intent, assumptions, constraints, performance expectations, and correctness criteria. Requirements engineering has long recognized that software requirements are frequently incomplete or open to multiple interpretations, and that translating them into working systems typically requires trained professionals and iterative processes of analysis, design, implementation, and validation Zadenoori et al. (2025) . Although code-trained LLMs have demonstrated strong synthesis capabilities Chen et al. (2021) , recent work shows that ambiguous or incompletely specified requirements can substantially degrade generated code quality, and that models often fail to detect or resolve such ambiguity without external guidance Yang et al. (2026) ; Fang et al. (2026) . These challenges are especially amplified in high-performance parallel programming. MPI programs coordinate distributed processes through explicit communication, so correctness and performance depend on how computation, data, synchronization, and communication are distributed across processes. Errors in decomposition, message ordering, collectives, boundary exchange, or memory layout can cause incorrect results and deadlocks Li et al. (2019) ; Chen et al. (2020) ; Hilbrich et al. (2012) ; Huang et al. (2020) ; Droste et al. (2015) ; Li et al. (2018) ; Yu (2018) . Many performance issues are also execution-dependent: code may compile and run correctly yet still suffer from communication overhead, root bottlenecks, inefficient decomposition, or rank-level imbalance that emerges only at runtime and scale Adhianto et al. (2010) ; Knüpfer et al. (2012) . Thus, MPI code generation is better viewed as an execution-grounded optimization problem than as one-shot synthesis. Iterative refinement approaches used by LLMs primarily optimize for functional correctness or unit-test success and rarely incorporate compiler diagnostics, static analysis, runtime profiling, or utilization metrics into a unified optimization objective. Furthermore, they typically discard optimization experience after each task rather than accumulating reusable domain knowledge across tasks. We present MetaFORGE , an execution-grounded meta-learning framework for MPI C code generation. Rather than optimizing only an individual generated program, MetaFORGE treats the persistent skill specification —the natural-language instructions that condition generation—as an adaptive policy refined within and across tasks. Each candidate program is compiled, tested, statically analyzed, executed, and profiled; the resulting evidence is combined into a reward that penalizes correctness failures, compiler warnings, static-analysis findings, externally measured whole-job runtime, and load imbalance. MetaFORGE then converts the diagnostics and reward trends into a textual gradient : a natural-language update signal that identifies measured deficiencies and proposes revisions to the skill. A second model call applies the gradient while preserving unrelated instructions. Figure 1 summarizes this closed-loop process. Beyond within-task skill refinement, MetaFORGE integrates automated execution, MPI-aware diagnostics, per-rank runtime profiling, deterministic skill versioning, and persistent external memory. The memory system stores iteration-level evidence and distills reward-improving episodes into compact guidance indexed by MPI constructs, parallel patterns, and observed correctness or performance symptoms. The skill captures broadly applicable generation behavior, whereas memory selectively retrieves more specific optimization experience from prior runs. Because both artifacts are external to the model, the framework supports inspectable cross-task transfer without parameter fine-tuning. MPI therefore serves as a demanding testbed for execution-grounded skill refinement and reusable optimization knowledge in language-model agents. Our central hypothesis is that execution-grounded refinement of persistent coding skills can improve program correctness, static-analysis quality, runtime performance, and rank-level load balance beyond zero-shot generation and general-purpose textual-gradient refinement. This work makes three contributions. (1) We introduce MetaFORGE , an MPI-aware meta-learning harness that optimizes persistent LLM skill specifications using correctness tests, compiler diagnostics, static-analysis findings, externally measured whole-job runtime, and rank-level load-imbalance measurements. Its two-stage refinement procedure converts this execution evidence into an explicit textual gradient and then applies the gradient while preserving unrelated skill instructions. (2) We develop a persistent cross-task memory mechanism that separates detailed iteration episodes from compact, reward-supported optimization lessons.
