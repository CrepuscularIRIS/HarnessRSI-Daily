arXiv: 2611.33612    title: Failure Broadens, Success Sharpens: Continual Adaptation of Tool-Use Agents Across Diverse Tasks with Dual-Polarity Memory

[abstract]
Large language model agents can self-improve over time by utilizing procedural memory derived from prior task trajectories, yet the distinct utilities of memories derived from local successes and failures remain underexplored. This work studies this question in a realistic setting with heterogeneous streams of multi-domain tool-use tasks and various environment constraints common in real-world scenarios. We develop \emph{Dual-Polarity Memory with Periodic Maintenance} (DualPM), a simple, retrieval-free memory workflow characterized by (1) customizable reflection and procedural memory generation from both local successes and failures within each trajectory, and (2) periodic memory consolidation over long task streams under a given memory capacity, preventing memory explosion. Online prequential evaluation with fine-grained metrics reveals that failure memory more strongly broadens coverage, success memory better streamlines execution, while combining both polarities effectively integrates both benefits. Further studies demonstrate that DualPM enables cross-domain memory generalization and continual memory adaptation, while external evaluation on EvoMemBench reveals the portability and effectiveness of DualPM as a general long-term procedural memory method.

1.1 Background and related work As applications of large language model (LLM) agents increasingly emphasize utility in multi-session, long-horizon settings, externalizing experiences from past tasks as reusable memories or skills has become a common approach to enable continual personalization, adaptation, and improvement of AI agents ( Huang et al., 2026 ; Zhang et al., 2026 ) . Rather than retaining noisy raw interaction histories, training-free methods on agent memory or skills typically compress prior experience into knowledge or procedural guidance that can inform future task execution ( Huang et al., 2026 ) . A prominent strand of research in this direction derives reusable procedural guidance primarily from successful task executions. For example, Agent Workflow Memory ( Wang et al., 2025 ) abstract successful trajectories into workflows; SkillWeaver ( Zheng et al., 2025 ) synthesizes tool interfaces from successful practice runs. Meanwhile, failed trajectories may carry distinct values that can be utilized through self-reflection. Reflexion ( Shinn et al., 2023 ) , an early pioneer in reflective self-learning, converts feedback from failed attempts into guidance for subsequent trails; recent work also showed that corrective updates derived from failures could improve computer-use agents ( Sun et al., 2026 ) . Recent trajectory learning approaches—including ExpeL ( Zhao et al., 2024 ) , ReasoningBank ( Ouyang et al., 2026 ) , SkillOpt ( Yang et al., 2026b ) , MUSE ( Yang et al., 2026a ) and Trace2Skill ( Ni et al., 2026 ) —draw on both successful and failed trajectories to derive reusable procedural guidance. These studies established that agents can self-improve at inference time by utilizing both previous successes and failures that are primarily judged and measured by benchmark-style, verifiable final task success. Final-task success alone provides limited insight into whether memories derived from successful and unsuccessful behavior serve different functions or how they affect actions within a multi-step trajectory. Successes and failures can also occur locally within a trajectory rather than only at the episode level ( Cao et al., 2026 ) . A successful trajectory may contain local failures worth avoiding or improving, while a failed trajectory may contain effective behaviors worth reusing. Furthermore, the explicit outcome signals available in benchmark environments are often absent in the real world. In real-world user-facing scenarios, agents may also face incomplete environment information, noisy tool interfaces, ambiguous user requests, and domain-diverse task streams. Under these conditions, deriving and maintaining a durable pool of procedural guidance over long, heterogeneous task streams remains challenging and underexplored. 1.2 Objectives and Contributions This work studies cross-session procedural memory in a realistic setting where an agent handles a heterogeneous stream of multi-step, multi-domain tool-use tasks under various constraints: user requests may be implicit; the tool set is large, noisy, and not fully visible upfront; evaluation ground truth is not available to the memory workflow; and the memory pool has a fixed capacity. The memory mechanism must therefore determine procedural lessons that remain durable and applicable to tasks from different domains, and continuously maintain the memory pool based on observations from newly completed task episodes. Our primary research question is how success and failure memories, independently and jointly, affect agent performance. To answer this, we introduce Dual-Polarity Memory with Periodic Maintenance (DualPM), a simple, retrieval-free memory workflow that reflects on completed task episodes, drafts success and failure memories, and periodically consolidates them into separate memory pools. Through online, prequential evaluation and fine-grained measurements of intermediate task stages, we find that the two memory polarities have complementary utilities: failure memory broadens coverage more, success memory improves efficiency more, and their combination effectively integrates both benefits. Case studies and analyses demonstrate that DualPM supports continuous memory adaptation after the procedural memory pool of a user is transferred to another user task sequence with a distinct domain composition. External evaluation on EvoMemBench ( Wang et al., 2026 ) further reveals the effectiveness of DualPM as a portable long-term procedural memory method that works across different task environments and backbone models.
