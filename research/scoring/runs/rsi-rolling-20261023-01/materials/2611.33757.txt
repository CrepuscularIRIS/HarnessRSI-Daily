arXiv: 2611.33757    title: TransHarness: From Benchmark Overfitting to Transferable Harness Evolution

[abstract]
Harness evolution offers a path to improving coding agents without updating model weights. However, existing methods can overfit their evolution benchmarks, producing gains that fail to carry over to new tasks. To address this challenge, we introduce Transferable Harness Evolution (TransHarness), which evolves harness intervention policies from same-task success-failure contrasts. These policies couple execution-context triggers with diagnostic guidance, enabling task-dependent checks and corrections beyond the source executions. Cross-task replay and independent semantic selection retain policies that intervene selectively and ground corrections in current-task evidence rather than source-specific solutions. We further curate an independent evolution set for cross-distribution transfer and conduct a cross-benchmark evaluation covering multiple strong models and a range of lightweight and mature harnesses. Experiments show that, with only 300 source trajectories from outside the test distribution, TransHarness further improves strong agents across distinct target benchmarks, demonstrating transferable harness evolution beyond benchmark overfitting. Specifically, TransHarness achieves state-of-the-art scores of 76.4% on DeepSWE v1.1 and 95.5% on Terminal-Bench 2.1, surpassing the strongest baseline model, GPT-6 Astra, by 2.4 and 5.6 percentage points, respectively.

[intro/head from cached fulltext]
Coding agents rely on harnesses to organize tool use, interpret feedback, and verify task outcomes ( Yang et al., 2024b ; Wang et al., 2025 ) . Harness evolution improves these execution mechanisms using experience from past tasks, offering a path to stronger agents without updating model weights ( Zhang et al., 2026b ; Lee et al., 2026 ; Wu et al., 2026a ) . However, gains on the tasks that drive evolution may fail to carry over to new tasks. SICA selects agent versions on a fixed task suite ( Robeyns et al., 2025 ) , Meta-Harness searches for and evaluates coding harnesses on the same TerminalBench-2 tasks ( Lee et al., 2026 ) , and Self-Harness selects candidates using feedback from held-out tasks within the benchmark ( Zhang et al., 2026a ) . Such feedback can favor adaptations to recurring benchmark characteristics, making benchmark overfitting difficult to distinguish from transferable improvement. DGM and ModularRSI test cross-benchmark transfer ( Zhang et al., 2026b ; Wu et al., 2026a ) , yet sustaining gains under distribution shift remains challenging. Our Meta-Harness reproduction illustrates this gap. It improves on our independent evolution set, but its success rate falls on DeepSWE v1.1 ( Figure 1 a ). To improve agents in practical settings, harness evolution must also benefit strong models running in mature harnesses. Existing methods can improve minimal starting systems, such as DGM’s harness with basic execution and editing tools and Self-Harness’s minimal DeepAgent ( Zhang et al., 2026b ; Zhang et al., 2026a ) . How to improve mature systems remains an open question. In HarnessOpt-Bench, an evolved simple harness still trails mature OpenCode when both use the same model and evaluation tasks ( Ursekar et al., 2026 ) ( Figure 1 b ). As baseline success increases, fewer failures remain to recover and more successful executions are at risk of regression. A positive net gain on strong agents therefore requires a lower ratio of the regression rate to the recovery rate. If the ratio is too high, overall performance can decline even when evolution recovers some failures ( Figure 1 c ). To transfer gains to strong agents, interventions must uncover overlooked problems while preserving behavior that already works. A correction can be specific to its source task even when the underlying execution failure recurs across task distributions. To address this challenge, we introduce Trans ferable Harness Evolution (TransHarness), which evolves when and how a harness intervenes during execution. TransHarness derives intervention policies from contrasts between successful and failed executions of the same task. Each policy pairs a trigger based on observable execution context with diagnostic guidance. The guidance directs agents to task requirements and evidence, allowing the same decision problem to receive different corrections across tasks. Cross-task replay and independent semantic selection together retain policies that intervene selectively and guide corrections based on evidence from the current task, making them usable beyond the original source-task solution ( Figure 2 ). To test whether harness evolution transfers across task distributions, we construct an independent evolution set and characterize how it differs from the target benchmarks in code repositories, task types, and application domains. For each model and harness configuration, we run the baseline agent on the evolution set and use the resulting trajectories to generate and select intervention policies. We then evaluate the evolved systems on the target benchmarks, covering multiple strong models and both lightweight and mature harnesses. TransHarness achieves state-of-the-art scores of 76.4% on DeepSWE v1.1 and 95.5% on Terminal-Bench 2.1 ( Huang & Jiang, 2026 ; The Terminal-Bench Team, 2026 ) , exceeding GPT-6 Astra by 2.4 and 5.6 percentage points, respectively. Our main contributions are as follows. • We find that gains on source tasks can turn into losses when transferred to a new benchmark. We derive the condition for harness evolution to yield a positive net gain on target tasks. At a fixed recovery rate, a higher baseline success rate allows a lower regression rate. • We propose TransHarness, which evolves harness intervention policies from same-task success–failure contrasts. In relevant contexts, these policies guide agents to reassess decisions using current-task evidence. Cross-task replay tests how selectively they activate, and independent semantic selection checks whether diagnoses are supported and whether guidance depends on source-task solutions. • We construct an independent evolution set to evaluate transfer across task distributions. Experiments with multiple strong models in lightweight and mature harnesses demonstrate the transferable gains of TransHarness, which achieves state-of-the-art performance on both DeepSWE v1.1 and Terminal-Bench 2.1.
