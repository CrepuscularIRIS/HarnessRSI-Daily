arXiv: 2611.34250    title: MedSkill-E$^{2}$: Evaluating and Evolving Skills for Medical Agents

[abstract]
Large language model (LLM) agents increasingly use skills to access domain knowledge and complete real-world tasks. We observe that even when a skill specifies the rules and procedures needed for a task, agents may fail to apply them effectively during autonomous execution, a phenomenon we call skill Enable But Underuse (EBU). This issue is particularly consequential in medical tasks, where overlooking a single critical constraint can yield a plausible but incorrect result. To evaluate and address EBU, we introduce MedSkill-E$^{2}$, a framework for evaluating and evolving skills for medical agents. We construct EBU-Bench, a challenging benchmark covering 12 medically relevant task groups and associated skills, to evaluate agents' ability to use available skills autonomously. We quantify the EBU gap as the difference in skill-use accuracy between autonomous use and explicitly guided reading and application of the same skill. On EBU-Bench, all evaluated model-harness combinations exhibit EBU, with a mean gap of 43.94 percentage points (pp). For the same model, skill-use accuracy under autonomous use differs by up to 38.96 pp across harnesses. Motivated by these observations, we propose EBU-Evolve, which uses execution feedback from autonomous and explicitly guided skill use to distill effective guidance into reusable skill instructions. Relative to their pre-evolution versions, the revised skills improve skill-use accuracy during autonomous execution by 33.33 to 55.17 pp and continue to yield improvements when transferred across multiple models and harnesses. Our results show that autonomous skill-use accuracy varies across harnesses with the model and skill held fixed, and model rankings can change. EBU can persist even after a skill is opened. EBU-Evolve improves autonomous skill-use accuracy on unseen tasks within the same skill, with gains transferring across models and harnesses.

[intro/head from cached fulltext]
Large language model (LLM) agents use skills to access domain knowledge and apply it to specific tasks. A skill organizes the methods, tool-use instructions, and operating procedures needed for a class of tasks into a reusable resource, so that agents need not work out a solution procedure anew for each problem. This support is particularly important in medicine and related research: clinical calculations require accurate application of formulas and their constraints, while evidence review requires adherence to explicit assessment criteria. Skills offer a direct way to standardize these operations. Skills have also begun to emerge for healthcare and the life sciences ( Xu et al., 2026 ) . However, on medical benchmarks and practical medical research tasks, we observe that agents sometimes fail to apply the methods in a skill effectively, even when an applicable skill is provided and its purpose and conditions of use are specified in its description. In other cases, changing the execution framework (harness) while holding the model and skill fixed reduces or even eliminates the performance gains previously obtained from the skill. These observations raise a question: in real medical applications, how much assistance can an available skill provide, and how much of that benefit can an agent realize when solving tasks autonomously? We further find that some previously unsuccessful tasks can be completed when the agent is directed to use a particular skill and given corresponding execution requirements. We call this additional guidance “operational support” and use task performance under this condition as an empirical reference for the benefits achievable with the skill. We term the phenomenon in which the same skill supports task completion under operational support but its corresponding benefits remain unrealized during autonomous execution skill Enable But Underuse (EBU). EBU may not be widespread across medical tasks, but when it occurs, agents produce plausible results that do not comply with the specified procedures, warranting dedicated study. We therefore identify tasks exhibiting EBU during benchmark construction and investigate two questions: how underuse on these tasks varies across models and harnesses, and whether revising reusable skill instructions can improve autonomous execution. To study this problem systematically, we introduce MedSkill-E², a framework for evaluating and evolving skills for medical agents that comprises EBU-Bench and EBU-Evolve. EBU-Bench contains 331 tasks and their associated skills, combining tasks from public benchmarks with tasks authored around research questions. Evaluation is organized around reusable skills, each intended for a class of problems. We select task–skill pairs from this collection and evaluate nine advanced language models under two harnesses. Mean skill-use accuracy is 38.38% when models use skills autonomously and 82.32% with operational support; on EBU-Bench, all evaluated model–harness combinations exhibit EBU. Even with the model and skill held fixed, performance under autonomous use varies substantially across harnesses. Operational support externally identifies a skill to use and provides general execution requirements for the task, but such guidance is usually unavailable in advance in practical settings. Notably, these supplementary instructions do not disclose any domain knowledge or operational steps specific to the task. We therefore propose EBU-Evolve to distill effective guidance from operational support into reusable skill instructions. The method revises a skill using paired execution feedback from the same task under autonomous use and operational support, and selects a revised version based on task performance under autonomous use. The revised skill can then be used directly for autonomous task solving without additional operational support for individual tasks. Experiments show that the revised skills improve overall skill-use accuracy under autonomous use on test tasks excluded from revision and selection, and continue to yield improvements when transferred across models or harnesses.
